# Jev 雀魂 Windows 侧边助手 · 0.2

## 本地自动流程调试版

源码入口默认开启自动运行，按进程自动连接雀魂窗口，通过 Windows Graphics Capture 捕获游戏自身的画面。切换到其他应用或窗口被遮挡时继续捕获，无需框选桌面；雀魂最小化或关闭时明确显示原因，恢复窗口后自动重连。每秒截图、识别并交给 Jev 推荐，无需点击“截取一次”或“分析这手牌”。手牌框会自动为最右侧摸牌和鼠标悬停抬高的牌预留空间。相同手牌与动作状态不变时保留原推荐，界面显示最近截图、最近推荐及截图到建议的耗时。

主窗口仅保留推荐牌、候选及简短状态。“整体策略”持续显示本局牌型方向，等待摸牌和后台计算时保留，方向变化才改写，新一局清除上一局内容；“当前决策”随每次推荐更新本次弃牌、向听、进张或听牌等待。截图预览、手牌输入、区域校准与牌桌信息位于“设置”对话框。普通五条的四根绿色与一根红色不会再仅因红色部分被当成赤五条。

状态分别显示 Jev 加载中、正在寻找手牌、等待摸牌、等待完整手牌、Jev 运算中和建议已更新。识别流程不以置信度或连续稳定两帧作为门槛，未读到完整局面时下一秒自动重试。手动输入是可选模式；重新勾选自动运行即恢复自动流程。界面牌名统一使用“条”。

截图流程读取吃碰提示与最后弃牌标记，将游戏实际提供的吃、碰和跳过候选交给 Jev 评分。吃碰前后的手牌变化用于追踪自己的副露，随后自动继续推荐弃牌；本机保存当前局的副露上下文供重启恢复。自己的副露也可在框选区域菜单中指定。默认牌河区域适配标准四人桌，改变窗口布局时可重新框选。

本地调试数据位于 `runs/live-debug/`，包含 GPU 推理检查、事件耗时和调试截图；只有设置 `JEV_DEBUG_DIR` 时才记录截图。电脑对局测试不代表真人胜率或所有皮肤与窗口布局的识别结果。

启动时自动加载 Jev，并执行一次真实推理预热。独立状态栏显示“加载中 / 预热中 / 已就绪”，预热成功后才显示“可以开始匹配”；请先启动工具并等到已就绪，再进入游戏匹配。新流程需重新启动源码版后生效，已发布安装包不包含尚未发布的本地修改。

勾选“自动执行推荐”后，工具根据识别牌框点击弃牌，并可执行立直和唯一组合的吃碰动作；推理后需再核对一张新截图，同一决策只点击一次。多个吃牌组合的选择界面尚未支持。切换到其他应用会暂停点击，返回雀魂后恢复；Esc 停止自动执行。以下旧版操作说明仍含手动流程，以本节源码调试版行为为准。

## 免Python的Windows发布版

当前吃碰策略问题、状态格式差异与服务器训练交接见[问题说明和验证计划](../plans/desktop-call-policy-server-handoff.md)。第二阶段原版推理参数现单独发布，0.3.0构建目标使用上方组合；模型偏好分仍不能当作策略正确性或胜率的证明。

下载并双击[安装程序 JevMahjong-Setup-0.2.1-win-x64.exe](https://github.com/YokyYao/JevMajhong/releases/download/desktop-v0.2.1/JevMahjong-Setup-0.2.1-win-x64.exe)即可。安装程序自动下载、SHA256校验并安装运行组件，创建桌面快捷方式；无需手动下载Runtime ZIP，也无需安装Python、pip或CUDA Toolkit。全部组件在[GitHub Releases](https://github.com/YokyYao/JevMajhong/releases)发布。

运行组件包含Python、CUDA版PyTorch、截图识别组件和已确认的校正版2参数。完整组件约4.8GB，压缩下载约3GB；安装时需要联网，并预留约12GB临时与安装空间。GitHub单文件上限为2GiB，因此按文件拆成多个独立ZIP，由安装程序自动处理。首次启动自动加载Jev，并联网下载固定版本的Qwen底座，后续使用本地缓存；需要可用的NVIDIA驱动。截图区域和自己的皮肤仍需在界面中首次校准。

发布前会实际运行**打包后的EXE**，检查界面、识别器和CPU模型推理，再通过本地HTTP服务下载安装同一组组件，并检查安装后的界面、识别器及实际CPU模型推理。Windows构建机没有NVIDIA GPU，因此这项检查不替代用户显卡实测。构建状态见[Windows EXE构建流程](https://github.com/YokyYao/JevMajhong/actions/workflows/windows-release.yml)。

打包时从已经公开的2000步归档恢复五份冻结输入文件，再应用256个校正参数；评分头张量及16项运行配置与已确认模型完全一致，并逐文件校验。此次按用户要求公开发布程序及其推理参数，训练逐场、特征和诊断明细不加入发布包。

## 安装与启动

1. 安装Windows版 **Python 3.12 x64**，保留Python Launcher。NVIDIA驱动需支持所安装的CUDA PyTorch。
2. 将私有交付的`JevMahjong-Windows-v0.1.1.zip`解压到一个可写文件夹。
3. 双击`Install.cmd`。它在工具目录创建独立环境，安装界面、识别和CUDA版PyTorch；依赖下载可能达到数GB。
4. 双击`Launch.cmd`。在“设置”中点击“加载Jev到NVIDIA GPU”。首次会下载固定版本的Qwen底座，后续使用本地缓存。

0.2发布包附带推理参数、识别模型和字体；源码仓库保留可校验的恢复脚本。源码开发时可先安装`desktop/requirements-ui.txt`体验牌理模式；使用Jev还需要`desktop/requirements-model.txt`，再运行`python scripts/prepare_desktop_release.py`与`python desktop/fetch_assets.py`准备资源。

```powershell
python -m desktop.jev_sidecar.app --demo
```

## 实机校准

打开雀魂牌桌，将助手停靠在一侧。点击“框选牌桌”圈住游戏区域，再选择“自己的手牌”并点击“框选区域”，紧密圈住所有手牌，包括最右侧摸牌。随后点击“截取一次”，核对识别出的牌。

牌代码支持`123m456p789s东白中`，赤五为`0m/0p/0s`。点击识别出的单张牌可以修正；也可以直接编辑整手牌。**自己的手牌按画面从左到右输入**，最右侧作为摸入牌；自己立直后只推荐该摸入牌。

自定义牌面可能超出预训练识别器的覆盖。把当前手牌校正后点击“保存为当前牌面模板”，即可在本地适配该皮肤。已有模板仍不确定的新牌会要求继续校正。改变皮肤、窗口尺寸、显示缩放后应重新框选和校准。模板保存在本机，不上传。

自动运行每秒截图检查牌桌。同一手牌与动作状态不变时保留推荐，不重复调用 Jev；新摸牌、吃碰和牌提示或立直状态变化时才重新计算。出牌后识别为13张且没有动作提示时等待摸牌；副露后也支持11/8/5/2张的弃牌阶段。旧局面推理完成后，如果牌面已改变，结果会被丢弃。

## 公开牌面

推荐牌下方显示依据当前手牌与推荐动作生成的简短牌型方向，听牌时列出等待牌。这是牌理说明，不是模型内部思考，不增加模型调用。

可继续框选自己、下家、对家、上家的牌河及宝牌指示牌；侧向牌河可以设置90/180/270度旋转。本场和立直棒会从左上角宝牌栏下方自动识别并更新到“牌桌信息”，数值变化时会重新请求推荐，包括归零；不弹识别错误提示。使用不同布局时可选择“立直棒与本场（整行）”框选对应的一整行，左侧是立直棒、右侧是本场。分数、庄家、场风、立直状态和副露继续在“牌桌信息”中核对。

副露每组用逗号分隔，例如`123m,555p`，暗杠`a:1111z`，加杠`k:5555p`。截图中的牌河是当前仍在河里的牌，不要再把已被鸣走的牌重复加入。宝牌栏输入**指示牌**，例如指示牌4m对应实际宝牌5m。

未确认的牌河会标成未知，进张数按可见信息给出上界，防守信息也会注明缺失。单张截图无法恢复全部历史手切/摸切等时序，Jev会收到明确的截图状态标记。源码调试版支持弃牌及截图中已出现的吃碰、和牌选项。十四张手牌出现立直按钮时，自动将“立直 → 打某张牌”与普通弃牌交给 Jev 比较；推荐立直时先点击游戏的立直按钮，再单击推荐牌。识别到取消选牌控件时，只推荐听牌弃牌。勾选自动执行后，工具会点击普通弃牌、立直及已支持的动作；复杂吃牌组合尚需补充处理。

## 当前效果与验证范围

本地使用校正版2，头指纹`b1248fbc9c9bd1a768a9eaf5fdb5241c82c96ac50eaabf8e0ca8fed885bec1ea`。它在固定四人东风、三个规则对手的独立仿真中，相对原2000步净得点+96.29点/场，配对95%区间[13.22,179.36]，每个模型2048场。**该结果不等于截图工具在真人雀魂中的胜率**。

桌面端弃牌特征已与训练环境的真实观测核对，100副随机手牌的向听计算一致；还检查了立直摸切限制、可见牌数守恒、模板校准与过期推理结果。公开参考截图完成牌面模板校准后能读回该14张手牌；这只是功能测试，不是独立识别准确率评测。

实际调用同一检查点的Linux GPU测试已通过，并覆盖5个可选弃牌的非平凡选择。RTX5000 Ada上的两个热机请求约51/39ms，测试峰值显存约1.53GiB；首次请求和冷缓存加载会明显更慢。这些不是Windows实机速度承诺。模型偏好分只表示动作相对偏好，不是胜率或和牌率。

## 本地数据与排错

截图在内存中处理；只有明确保存校正模板时才保存牌面切片。校准配置和模板位于`%LOCALAPPDATA%\JevMahjong`，启动错误日志为该目录的`error.log`。识别模型、字体和底座只在安装/首次加载时下载，推荐不调用在线AI接口。

识别缺牌时收紧手牌区域，修正牌面并保存模板；出现同牌超过4张时检查牌河、宝牌和副露重复计数。GPU不可用时核对驱动和CUDA版PyTorch安装；可切换到明确标记的牌理引擎继续核对界面。
