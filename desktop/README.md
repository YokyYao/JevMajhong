# Jev 雀魂 Windows 侧边助手 · 0.1

本地截图、本地麻将牌识别、本机 NVIDIA GPU 推荐。窗口可置顶并靠右停靠，支持导入PNG/JPG、实时截取牌桌、手牌与公开牌面校正、前三候选、向听数及有效进张。Jev使用已经独立确认的校正版2；牌理引擎单独标明。

本版提供的是**Windows源代码启动包**，含安装/启动脚本和私有交付的已训练检查点，不是预编译EXE。界面、规则计算和实际模型推理已在Linux验证；Windows依赖的Python3.12 x64安装包已核对，Windows实机仍需首跑验证。可选的`Build-Exe.ps1`用于在自己的Windows上生成EXE，尚未验证其产物。

## 安装与启动

1. 安装Windows版 **Python 3.12 x64**，保留Python Launcher。NVIDIA驱动需支持所安装的CUDA PyTorch。
2. 将私有交付的`JevMahjong-Windows-v0.1.0.zip`解压到一个可写文件夹。
3. 双击`Install.cmd`。它在工具目录创建独立环境，安装界面、识别和CUDA版PyTorch；依赖下载可能达到数GB。
4. 双击`Launch.cmd`。在“设置”中点击“加载Jev到NVIDIA GPU”。首次会下载固定版本的Qwen底座，后续使用本地缓存。

公开仓库只包含代码与文档，新检查点和识别/字体二进制不推送GitHub。私有启动包附带模型文件；仅下载仓库源码时，可先安装`desktop/requirements-ui.txt`体验牌理模式，使用Jev还需要本地校正版2检查点及`desktop/requirements-model.txt`。

```powershell
python -m desktop.jev_sidecar.app --demo
```

## 实机校准

打开雀魂牌桌，将助手停靠在一侧。点击“框选牌桌”圈住游戏区域，再选择“自己的手牌”并点击“框选区域”，紧密圈住所有手牌，包括最右侧摸牌。随后点击“截取一次”，核对识别出的牌。

牌代码支持`123m456p789s东白中`，赤五为`0m/0p/0s`。点击识别出的单张牌可以修正；也可以直接编辑整手牌。**自己的手牌按画面从左到右输入**，最右侧作为摸入牌；自己立直后只推荐该摸入牌。

自定义牌面可能超出预训练识别器的覆盖。把当前手牌校正后点击“保存为当前牌面模板”，即可在本地适配该皮肤。已有模板仍不确定的新牌会要求继续校正。改变皮肤、窗口尺寸、显示缩放后应重新框选和校准。模板保存在本机，不上传。

勾选“实时识别”后，每秒检查一次牌桌；连续两帧手牌稳定且置信度足够时更新建议。识别为13张时等待自己出牌；副露后也支持11/8/5/2张的弃牌阶段。旧局面推理完成后，如果牌面已改变，结果会被丢弃。

## 公开牌面

可继续框选自己、下家、对家、上家的牌河及宝牌指示牌；侧向牌河可以设置90/180/270度旋转。分数、庄家、场风、本场、立直棒、立直状态和副露在“牌桌信息”中核对。

副露每组用逗号分隔，例如`123m,555p`，暗杠`a:1111z`，加杠`k:5555p`。截图中的牌河是当前仍在河里的牌，不要再把已被鸣走的牌重复加入。宝牌栏输入**指示牌**，例如指示牌4m对应实际宝牌5m。

未确认的牌河会标成未知，进张数按可见信息给出上界，防守信息也会注明缺失。单张截图无法恢复全部历史手切/摸切等时序，Jev会收到明确的截图状态标记。本版只推荐弃牌；吃碰杠、立直、和牌等动作由游戏合法按钮与玩家判断，和牌形会提示先查看自摸/和牌按钮。

## 当前效果与验证范围

本地使用校正版2，头指纹`b1248fbc9c9bd1a768a9eaf5fdb5241c82c96ac50eaabf8e0ca8fed885bec1ea`。它在固定四人东风、三个规则对手的独立仿真中，相对原2000步净得点+96.29点/场，配对95%区间[13.22,179.36]，每个模型2048场。**该结果不等于截图工具在真人雀魂中的胜率**。

桌面端弃牌特征已与训练环境的真实观测核对，100副随机手牌的向听计算一致；还检查了立直摸切限制、可见牌数守恒、模板校准与过期推理结果。公开参考截图完成牌面模板校准后能读回该14张手牌；这只是功能测试，不是独立识别准确率评测。

实际调用同一检查点的Linux GPU测试已通过，并覆盖5个可选弃牌的非平凡选择。RTX5000 Ada上的两个热机请求约51/39ms，测试峰值显存约1.53GiB；首次请求和冷缓存加载会明显更慢。这些不是Windows实机速度承诺。模型偏好分只表示动作相对偏好，不是胜率或和牌率。

## 本地数据与排错

截图在内存中处理；只有明确保存校正模板时才保存牌面切片。校准配置和模板位于`%LOCALAPPDATA%\JevMahjong`，启动错误日志为该目录的`error.log`。识别模型、字体和底座只在安装/首次加载时下载，推荐不调用在线AI接口。

识别缺牌时收紧手牌区域，修正牌面并保存模板；出现同牌超过4张时检查牌河、宝牌和副露重复计数。GPU不可用时核对驱动和CUDA版PyTorch安装；可切换到明确标记的牌理引擎继续核对界面。
