# Jev Play v2 — Windows 0.4.0

下载并双击 **JevMahjong-Setup-0.4.0-win-x64.exe**。安装程序会自动下载并校验运行组件，无需自行安装 Python、pip 或 CUDA Toolkit，也无需手动处理 Runtime ZIP。

默认推荐模型更新为 **Jev Play v2**，同一套参数处理出牌、吃、碰、暗杠、大明杠和加杠。保留截图识别、本场与立直棒读取、侧边栏和原有校准。使用 NVIDIA 显卡需要本机显卡驱动；首次启动还需联网下载固定版本的 Qwen 基座。

升级时保留截图校准，旧版默认模型路径迁移到 Jev Play v2。模型校验或实际预热失败时不会显示已就绪。

这是按用户要求发布的试用版本。权重来自 v8 最终 2,088 步，只导出推理参数，参数值未改变。模拟评测的参照带有额外鸣牌修正组件，与原版 Jev Play v1 安装包不同；目前没有相对原版安装包的直接效果比较，也未证明真人对局胜率。统计区间和完整模拟结果见仓库实验记录。

发布流程检查冻结 EXE 与安装后程序的真实 CPU 推理，覆盖门清出牌、副露后出牌、吃、碰和三种杠；NVIDIA GPU 和实际截图使用效果仍需在本机验证。多种杠法的二次选择界面仍有原有使用限制。
