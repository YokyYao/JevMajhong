# Jev Play v2 — Windows 0.4.2

下载并双击 **JevMahjong-Setup-0.4.2-win-x64.exe**。已有0.4.0时直接覆盖安装到原目录，不要先卸载。

本次更新补充了碰按钮的视觉识别，修复吃碰推荐反复刷新时延后自动点击的问题，并改进碰后多组副露识别。鸣牌推荐生成后会立即请求新截图用于点击校验。

本机真人复测中的 10 个吃碰窗口均按模型建议点击跳过。该场未发生自己的碰牌，碰后自动出牌已做截图回放验证，仍待真人对局验证。

此次优化安装与升级方式：校验并复用已有Python、PyTorch及CUDA运行组件，程序和模型独立更新；未改变的模型也跳过下载。截图校准和已缓存的Qwen基座保留。首次安装、换到空目录或环境缺失／损坏时仍自动下载完整运行组件，无需自行安装Python、pip或CUDA Toolkit，也无需手动处理ZIP。

推荐模型仍为 **Jev Play v2**，来自v8最终2,088步；模型参数没有改变。同一模型处理普通出牌、吃、碰和三种杠。模拟确认尚未证明优于原版安装包或真人胜率提升。

发布前检查冻结EXE的真实CPU推理，并实测0.4.0覆盖升级、首次安装、无下载的重复安装、模型修复和缺失运行库的修复回退。安装后覆盖七种动作路径的真实推理。NVIDIA GPU和实际截图效果仍需在本机验证；多种杠法的二次选择界面仍有原有使用限制。
