# Jev Play v2 — Windows 0.4.4

下载 **JevMahjong-Setup-0.4.4-win-x64.exe**，选择原安装目录即可覆盖升级。安装器会校验并复用已有运行环境，保留截图校准和已下载的基座缓存。

## 修复

- **重启助手后停在「匹配确认」。** 旧版能认出确认按钮，但重新开启连打后需要先看到一局牌桌。新版在「自动执行推荐」和「连打」开启时，可直接处理当前弹窗。已经结束的上一场不计入新设定的场数。
- **多出一张结算页后漏点。** 连打按当前画面识别终局成绩、段位进度、宝匣、奖励和匹配确认。按钮出现顺序变化、跳过中间页，或「再来一场」弹窗位置变化时，也能处理已识别的页面。
- **立直选牌时卡住。** 灰牌被误读时，只有推荐弃牌的牌面和原牌槽都对得上才会点击。
- **牌河误识别阻塞出牌。** 当自动识别的牌河文本无法解析时，将该牌河视为未知，继续处理有效的摸牌。

## 连打

可设置 1 至 99 场，达标后停在结算页。点击只在雀魂窗口处于前台时执行，按 Esc 可以停止。

## 验证范围

本机冻结 EXE 通过自检和 16 张实况截图回放，其中包括卡住的匹配确认弹窗。回放确认重启后可从该页触发一次点击，已结算场数仍为 0。状态测试覆盖达到设定场数后停止。本次匹配确认修复尚未验证真人房服务端入队。

推荐模型沿用 **Jev Play v2**（v8，2,088 步）。发布包使用默认牌面检测权重，桌面端支持通过 `--tile-vision-profile` 指定本地实验识别配置。
