# Jev Play v2 — Windows 0.4.3

下载 **JevMahjong-Setup-0.4.3-win-x64.exe**，运行后选择原安装目录即可覆盖升级。安装器会校验并复用已有运行环境，保留截图校准和已下载的基座缓存。

## 修补的 Bug

- **吃碰后卡住、无法出牌。** 点击吃碰后等待 450 毫秒再取新帧，保留动画前的鸣牌状态。连续两帧手牌与副露对不上时，清除旧建议并扩大副露扫描范围。核对通过后重新推荐出牌。
- **吃碰窗口漏点或等待过久。** 同一个按钮窗口内保留已识别的目标牌，减少高亮闪动造成的目标丢失。多个吃碰组合使用两步点击，核对二次选择界面显示的牌后再选择推荐组合。
- **摸牌漏读或认错。** 根据可见牌槽补读漏掉的单张手牌。加入七条被误读成九条、普通五万被误判为赤五万，以及高光导致二万被误读成一万的复核。
- **漏点自摸或荣和。** 识别自摸按钮并核对和牌牌形。荣和按钮已识别、手牌已确认听牌时，可在放铳牌暂未读出时生成点击。和牌后等待下一局，避免在结算动画里再发弃牌指令。
- **截图卡在旧画面。** 等待点击结果或核对副露时，如果超过 2 秒没收到新画面，自动重连窗口捕获。
