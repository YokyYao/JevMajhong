# 新自然牌谱的冻结特征准备

独立复验 trust15 继续运行且保持冻结；并行准备下一轮研究需要的输入，不更新任何模型参数。

- 数据：新 TRAIN 的 8192 条反应（257场比赛）和 validation 的 2048 条反应（65场），每条生成原生、元数据已确认截图、元数据未知截图三个视图。总计目标是 **30720 次原生概率校验**，独立原始决策仍为10240条。
- 新 test 的2048条反应（65场）保持未编码、未作模型推理，不用于当前或下一轮选检查点。
- 编码器使用已确认旧模型的冻结 Qwen3.5-0.8B、LoRA 和指针头。模型版本、参考文件与输入分片校验和写入私有协议。每次提取都验证缓存张量重算的概率与原生接口一致；后续才可在这些冻结张量上研究新的鸣牌 query，不能把准备特征算作已训练新模型。
- 每64条原始决策写一个张量分片及独立完成凭据，包含协议摘要、张量摘要、校验次数和行身份。恢复时只复用身份、形状、摘要均匹配的已验证分片；未完成的分片重新编码，已完成但被改动的分片报错。文件锁防止两个进程同时写入。
- 任务由Slurm另行分配一张GPU，先检查没有其他计算进程。批作业上限2小时，作业内每分钟观察状态，最多观察2.5小时。完成标记只在所有train/validation分片和原生概率校验齐备、参考文件未改变后写出。集群重启会终止作业，后续仍需核实旧进程已结束后再恢复；观察器不能唤醒聊天。
- 当前独立复验不使用这些新特征或验证结果调整候选。复验完整结束并审查后，再确定新训练配方。测试继续封存；原始记录、缓存及诊断明细私有，只公开代码、配置和摘要。

配置为 `call-natural-features-20261110.json`；提交入口 `call_natural_features.slurm`；可恢复提取器 `scripts/cache_call_features.py`。五项缓存恢复/监控回归测试已通过，包括输入标签改变、协议改变、张量篡改、形状不符、缺少完成凭据及完成标记检查；实际GPU原生校验以运行完成的审计结果为准。
