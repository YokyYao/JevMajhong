# 评分头强化学习短程试验

2026 年 10 月 29 日启动。本轮从第一轮最终第 2000 步权重出发，冻结 Qwen 和全部 LoRA，只更新约 52 万参数的动作评分头，并训练一个独立的可见状态价值预测器。上一轮继续模仿训练产生的 400、800、1200 步模型均在同批牌山上退化，当前不再扩大该监督训练配方。

**执行结果：本试验累计32次更新后以 `stop_no_early_progress` 自动停止，未达到目标；独立确认未启动，旧权重保持不变。详见[结果和逐场证据](../reports/2026-10-29-head-rl-pilot/README.md)。以下保留预设方案，门槛未因结果修改。**

**种子协议更正：发现连续原始种子会共享移位牌山后，保留已完成的16次更新并停止旧验证。正式试验使用 `spaced-v1`，实际引擎种子为逻辑ID左移32位。通过 `head_rl_resume.slurm` 迁移至 `runs/head-rl-pilot-v2`，累计更新预算仍为64。细节及复现见[更正说明](../reports/seed-independence-erratum.md)。**

## 阶段目标

开发评估目标为半庄一位率至少 45%，并且比同一批牌山上的旧模型高至少 5 个百分点；两者取较高门槛。平均净得点不低于旧模型，末位率最多增加 3.125 个百分点。这是短程试验的筛查目标，不能以历史的 41.41% 代替新开发集的配对参考。

开发集只用于及时停止和选择方向。反复查看的 64 场开发对局不构成最终胜率提升证据；只有通过后，才冻结单一检查点进入另一批新牌山的独立确认。

## 奖励与优化

训练完整半庄轨迹，终局排名第一奖励 1，其他名次奖励 0，不使用原始点数、单局和牌、向听或真人标签作为奖励。净得点与末位风险作为独立门槛，避免未经定标的分数奖励压过一位率目标。

保留现有合法动作与牌效防守约束。训练行为分布为约束内动作概率的 95% 加 5% 均匀探索，PPO 的概率比使用这一实际行为分布；评估使用约束内贪心动作，与已测旧模型一致。

价值预测器只能看到从玩家可见状态编码得到的特征，以终局第一名指示值为训练目标。使用完整回合的蒙特卡洛回报，折扣为 1；优势为回报减去采样时的价值预测，并在当前轨迹批内标准化。

| 参数 | 预设值 |
| --- | --- |
| 可更新策略参数 | pointer 评分头，底座与 LoRA 全冻结 |
| 评分头学习率 | 0.000001 |
| 价值预测器学习率 | 0.0001 |
| PPO 裁剪 | 0.1 |
| 旧策略 KL 正则系数 | 1.0 |
| 熵正则系数 | 0.001 |
| 小批大小 | 128 个真实采样决策 |
| 每阶段 | 16 场训练半庄、最多 16 次优化器更新 |
| 全程上限 | 4 阶段、64 次优化器更新、最多 64 场训练半庄 |
| 保存频率 | 每 4 次更新保存评分头、价值预测器、优化器和随机状态 |
| 开发验证频率 | 每 16 次更新，完整 64 场开发半庄 |
| 试验墙钟上限 | 75 分钟，GPU 作业最多 90 分钟 |

底座与 LoRA 冻结后，采样时保存实际部署推理路径输出的决定位置和候选位置特征，只在这些固定特征上训练评分头。启动时必须验证特征重放可还原部署概率与约束后的贪心选择，避免训练与评估走不同输入路径。GPU 冒烟测试中使用的人工回报仅验证梯度，不计入训练或实战统计。

## 数据与对手隔离

训练种子从 1201000 开始，共最多 16 个种子，每个轮换四个座位。一半训练半庄面对三个规则基线，另一半面对一个冻结旧模型和两个规则基线。只更新候选玩家，旧模型与规则对手不更新。

开发集使用逻辑ID 1302000 至 1302015，共 16 个隔离的牌山流、64 场换座对局。候选与旧模型面对相同的三个规则基线，以便和历史评估口径一致。训练集和开发集不共用逻辑ID，且实际种子范围隔离。

独立确认保留逻辑ID 1402000 至 1402127，共 128 个新牌山流。只有开发目标达到时才启动，候选和旧模型各评估 512 场。确认阶段不更新参数，不改变奖励和约束，不再挑选其他检查点。

启动预检发现：先对受约束候选的 logits 归一化，可能改变原推荐路径在概率下溢时的平局选择。正式贪心评估已保持原路径的完整 softmax 后取约束内最大值规则。此前尚未更新参数的启动探针已封存，其种子段不并入正式开发集。

## 及时停止规则

- 任一阶段相对同批旧模型，一位率下降至少 6.25 个百分点、平均净得点下降至少 2000 点，或末位率上升至少 6.25 个百分点，立即停止。
- 第 32 次更新后，一位率若尚未比旧模型增加至少 3.125 个百分点，停止本配方并分析。
- 最多第 64 次更新仍未达到完整开发目标，停止，不自动延长。
- 采样批完全没有终局回报差异、出现非有限梯度、冻结层收到梯度、特征重放不一致或旧策略平均 KL 超过 0.01，都停止并保留诊断。KL 超限时回退本阶段更新。
- 墙钟达到 75 分钟时停止。已保存的完整对局、轨迹与检查点保留，不覆盖旧模型。

这些开发门槛是控制试验成本的工程规则，不是反复检验后的统计显著性结论。平均净得点使用终局原始点数减去起始 25000 点，不含顺位奖励换算。

## 独立确认与交付

确认阶段须同时满足：候选一位率至少 45%、相对旧模型至少增加 5 个百分点、按种子聚类的一位率差 95% 区间下界大于零、平均净得点不下降，以及末位率不超过旧模型 3.125 个百分点。未满足则停止该配方，保留旧策略。默认推荐策略不因开发结果而改变。

每次停止均输出 `pilot-analysis.json` 和 `analysis.md`，包含各检查点的一位率、净得点、末位率、停止原因、策略 KL、真实贪心动作翻转比例、采样奖励情况及后续分析。达标后另输出独立确认结果；未达标不宣称训练有效。

全新试验参数见 [`head-rl-pilot.json`](../head-rl-pilot.json)，入口为 `head_rl_pilot.slurm`。当前迁移参数见 [`head-rl-pilot-v2.json`](../head-rl-pilot-v2.json)，入口为 `head_rl_resume.slurm`，复用v1第16次检查点，原轨迹及状态保留。完整轨迹和优化器状态位于忽略的 `runs/`；原始底座、旧模型权重和封存的测试牌谱不修改。
