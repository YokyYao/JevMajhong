# 攻略启发的鸣牌得点学习

目标继续采用四人东风整场净得点。用户提供的[《雀魂日麻－从入门到自闭》合集](https://www.bilibili.com/read/readlist/rl80268)共14篇，已取得完整目录并读到与本次调整直接相关的五篇正文：[得点策略](https://www.bilibili.com/opus/245489524504592810)、[立直策略](https://www.bilibili.com/opus/247424226883243622)、[副露策略](https://www.bilibili.com/opus/249966705790407806)、[防守策略](https://www.bilibili.com/opus/255896990472891856)、[东风和南风策略](https://www.bilibili.com/read/cv2981142/)。部分其他章节未取得可读正文，不宣称通读全部14篇。这里只给技术映射与个人分析，不转载原文。

## 已确认的问题

最新自然数据候选的768场完整开发评估没有证明相对旧模型改善；和牌率提高的同时放铳率提高。[计分核查](../reports/2026-11-10-call-scoring-audit/README.md)已精确重现48场，219次和牌的四家支付额与独立库一致，包含11次副露和牌；未发现分数差额。下一步应改进收益与风险判断。

攻略中的副露、立直与防守章节讨论了速度、打点与退路的交换；东风章节侧重名次/PT。我们沿用用户选定的净得点目标，把这些条件做成可学习特征，不把攻略观点当作真实收益标签。文章年代较早，PT规则、通用断言与符番简化不直接写入引擎。例如四番是否达到满贯仍取决于符，不能一律认为立直再多一番不影响支付。

## 此次实际改动

`guide_call_features.py`增加34个只由自己手牌与公开状态计算的协变量，跳过动作的特征为0，参数由模拟得分学习：

| 攻略涉及的判断 | 代码中的可测量条件 |
| --- | --- |
| 副露加速与失去门清条件 | 首次副露、原/副露后向听变化、是否进听、已有副露数 |
| 副露后做什么役、是否保留价值 | 已固定副露中的役牌番数、全中张/一色材料、刻子数、保留宝牌与赤牌 |
| 手牌减少后的攻守交换 | 对所有立直威胁共同安全的手内现物数、吃碰后可用安全牌、立即可打的安全牌 |
| 东风进程与分差 | 巡目、晚巡、庄闲、本场、供托、距领先/末位点差 |

材料特征不是完整役种证明，未识别出役牌或断幺也不禁止鸣牌；混一色、对对和等路线仍由真实终局收益检验。筋与壁不作为绝对安全条件；对多名立直者使用其现物的交集。后续弃牌严格保留雀魂食替禁令，CPU测试直接与原生环境合法弃牌集合核对。原生动作的MJAI赤牌/字牌记法与状态mpsz记法已统一。

`guide_call_collector.py`复用已验证的单次合法鸣牌干预：同一牌山、同一完整前缀，只替换一次chi/pon/none，然后冻结策略延续到整场结束。每个控制与真实分支逐笔核对立直押金、和牌/流局收入支出及终局供托；分解和必须严格等于最终分减25000。不会因吃碰、番数、和牌次数或名次额外加奖励；放铳损失已经体现在终局分中，不重复扣罚。

## 首个训练阶段

配置`guide-call-points-20261110.json`：

- 冻结已确认B的普通出牌头、底座和LoRA，鸣牌延续教师固定为trust15；学习的是该固定延续策略下的局部动作价值，不是完整轨迹PPO。
- 32个全新训练牌山9010100–9010131、四座轮换、每座四次单次决策采样，最多512个有动作的配对标签。没有鸣牌决策的座位如实记录，不造标签。采样对手为三个固定牌效规则策略，不能冒称强对手训练。
- 每个完整牌山独立保存私有分片与摘要校验，可用`--resume`恢复；恢复必须与原配置、代码和权重完全一致。进行中分支不作为已完成训练数据。
- 用256维冻结指针交互特征与34维攻略协变量，拟合290参数的线性得分差模型；目标是替代动作与教师动作的终局分差除1000。按整个牌山做四折验证，同一牌山全部座位和副本必须同折。只在训练牌山内选择岭回归正则强度，保留零差值预测器作为基线；同动作精确零样本不用于稀释验证MSE。
- 若分组验证不优于零预测，记录失败并停止本配方的候选推进，分析样本覆盖和收益方差。即使通过，也只是得分差预测有效的初步信号，不能宣布实际增强或部署。

## 后续独立对局目标

预留9110000–9110031开发、9210000–9210127独立确认，不用于上述拟合。先实现并核对原生动作价值推理，再比较旧B、冻结父模型及候选的完整东风净得点。保留两种原对手组以便比较，并增加含冻结旧B对手的压力评估；不能仅对简单规则策略报告优势。具体对手组与主次指标须在候选对局前冻结。

不设固定+250/+500点否决线。小幅正向均值保留候选并扩大独立确认；区间跨零时不声称稳定提升。若完整开发均值不增且放铳风险增加，停止当前更新，分析实际分支后修改方案。报告和牌收入、放铳支出、被自摸支出、押金与流局，帮助区分速度、打点和防守的影响；顺位与一位率作辅指标。

本阶段只更新鸣牌价值学习；立直/默听、主动弃和与杠策略另设后续受控试验。现有弃牌约束和旧发布模型未更换。攻略特征在原生模拟输入上先验证，截图端缺失元数据的处理仍需独立回归。

公开代码、配置及摘要；原文缓存、真人牌谱、模拟逐场记录、特征与新权重均私有。本阶段采样与拟合不使用封存的人类test。
