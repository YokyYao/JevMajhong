# 四人东风前二率短程训练方案

**状态：已按用户要求取消作业253125，停止于第8次参数更新，保留0、4、8次检查点。第8次开发验证未完成，不据此报告整组胜率或判断提升。没有提交新的训练。以下保留本轮启动前的协议，不代表当前仍在运行。**

本方案在启动前固定。目标是提高四人东风完整对局的最终前二率，不把前二率解释成雀魂段位分收益。当前段位和房间未指定，因此不使用段位分奖励。本轮从原监督训练第2000步重新初始化，不继承上一轮未达标的强化学习候选。

## 对局、奖励和比较对象

- RiichiEnv 0.4.11，`4p-red-east`，`GameRule.default_mjsoul()`：四人赤牌东风，按引擎的连庄、延长和终局规则结束，不人为截断为固定四局。
- 只在整场最终结算发放奖励：第一或第二名为1，第三或第四名为0。无25000点硬门槛，无和牌、向听或额外净得点奖励。第一与第二的奖励相同，模型可能更愿意保二。
- 固定参考：`runs/semantic-2026-freegpu/checkpoints/step-002000` 的牌效防守约束版本。候选使用相同合法动作与约束；冻结Qwen底座及全部LoRA，只训练524800参数的pointer评分头和独立可见状态价值预测器。
- 训练对手：一半对局为三个规则基线；另一半为一个冻结旧模型加两个规则基线。只更新候选玩家。
- 开发及确认：旧模型与候选分别面对同样三个规则基线，使用相同牌山流、各换座四次。先实测旧模型的东风基线，之前的东南一位率不用于本轮门槛。

## 阶段目标与停止条件

主要指标为最终前二率。开发集每次64场，即16个独立牌山流各换座四次。目标须同时满足：

1. 候选前二率至少60%，并比同批旧模型提高至少6.25个百分点，取较高门槛。60%在64场中至少需要39次前二；相对提升至少需要多4次。
2. 平均净得点不低于旧模型；末位率最多比旧模型高3.125个百分点，即最多多2次末位。

| 检查点 | 计划和判据 |
| --- | --- |
| 更新0 | 保存初始化，评估旧模型64场东风基线 |
| 更新4、8、12、16、20、24、28、32 | 保存权重、优化器和随机状态 |
| 更新8 | 完整64场开发验证，检查退化和阶段目标；未提升仅允许再试一个阶段 |
| 更新16 | 若前二率比旧模型增加不足3.125个百分点，即不足多2场前二，立即停止 |
| 更新24、32 | 继续验证；连续两次未刷新前二率历史最好值则停止；更新32仍未达目标则结束配方 |

每次开发验证，任一明显退化就提前停止：前二率比旧模型低至少6.25个百分点、平均净得点低至少2000点、末位率高至少6.25个百分点，或一位率低至少12.5个百分点。第一名仅作为诊断和严重退化保护，不用它代替前二率选模。相同前二率不算刷新最好值。

另外，训练回报完全没有变化、非有限损失/梯度、冻结层收到梯度、推理特征不一致、完整训练轨迹平均旧策略KL超过0.01，都会停止或报错。KL超限回滚该阶段。已结束目录不能直接恢复再训或覆盖。

这些是控制试验成本的工程门槛。反复检查的16个开发牌山流不能提供最终统计收益证明；不以动作一致率或训练损失选模，也不承诺达到60%。

## 样本和计算预算

| 项目 | 固定设置 |
| --- | --- |
| 最大阶段 | 4 |
| 每阶段新训练样本 | 8个独立牌山流，各换座4次，共32场完整东风 |
| 每阶段优化更新 | 8次，minibatch 256 |
| 总上限 | 128场新训练对局、32次优化更新；不等于32场对局 |
| 保存 / 实战验证 | 每4次保存 / 每8次更新后64场开发验证 |
| Actor / critic学习率 | 5e-6 / 1e-4 |
| PPO clip / KL惩罚 / 熵系数 | 0.1 / 1.0 / 0.001 |
| 探索 | 在共同约束集合内5%均匀混合 |
| 信用分配 | gamma=1，完整终局回报；可见状态sigmoid价值基线，优势标准化 |
| 运行时间 | 训练及开发合计最多60分钟；单卡Slurm申请75分钟，包含预检和模型加载 |

相较上一轮，增加每阶段新轨迹数量，缩短重复更新和检查间隔；Actor学习率从1e-6调为5e-6，以监测到的KL与实战退化限制变化。本轮同时改变对局格式和目标，因此不能把变化归因于奖励函数这一项；这是实用短程筛查，不是单变量消融。

种子采用已经修正的 `spaced-v1`：实际引擎种子为逻辑ID左移32位，避免相邻半庄或东风共享移位牌山流。

- 训练逻辑ID：1501000至1501031，分阶段使用，不重复采样旧轨迹。
- 开发逻辑ID：1602000至1602015。
- 确认保留逻辑ID：1702000至1702127。

三者隔离，也不复用上一轮的开发/确认流。四次换座属于同一牌山流的分组，统计区间按牌山流计算，不当作四个独立样本。

## 达标后的独立确认

仅当开发门槛达到时冻结第一个达标检查点，停止训练，自动提交一次新牌山确认。候选与旧模型各512场，共128个新牌山流，确认不更新参数、不重新选检查点。

确认须同时满足：前二率至少60%、相对旧模型至少增加6.25个百分点、按牌山流聚类的配对前二率差95%区间下界大于零、净得点不下降、末位率最多增加3.125个百分点。未通过就结束此配方。即使通过，也只报告这组固定规则对手下的效果，默认推荐策略不会自动替换。
