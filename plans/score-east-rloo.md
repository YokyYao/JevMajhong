# 四人东风净得点：配对轨迹回报基线试验

**结果：已在第16次更新按无进展条件停止。旧模型平均净得点-634.375，更新8为-643.75，更新16为-710.9375，最终相对下降76.5625点/场；未达原目标，未提交确认或替换默认策略。以下保留原协议。结果及后续分析见[汇总](../reports/2026-10-29-score-reference-analysis/README.md)。**

开训前已完成[上一轮原因分析](../reports/2026-10-29-score-diagnosis/README.md)。主要观察是价值预测近似常数、每批轨迹使用不足、实际策略变化很小；奖励实现和推理数值嫌疑已经核对。本轮重新从监督训练第2000步初始化，不恢复已结束试验的优化器或候选权重。

## 保留得分目标，改变基线估计

奖励仍为完整四人东风终局 `(points-25000)/1000`，保留正负和大小，没有名次奖励或分数截断。使用RiichiEnv 0.4.11、`4p-red-east` 和 `GameRule.default_mjsoul()`，按规则处理连庄和延长。Qwen与LoRA冻结，更新524800参数评分头；不训练价值预测器。

每个训练逻辑种子和座位产生两个独立探索版本。两者在同一次参数更新前采集，使用完全相同的环境种子、座位和固定对手，策略采样种子分别由配置种子、牌山ID、座位和版本号确定。

```text
R0 = 版本0最终净得点 / 1000
R1 = 版本1最终净得点 / 1000
A0 = (R0 - R1) / 10
A1 = (R1 - R0) / 10
```

除以10是固定的优势缩放，不截断得分，也不将组内高低分改成二元胜负。回报相同的组保持零优势并保留在批次里。基线仅来自其他版本，不把自己的回报混入均值；采样时不向策略提供他家暗牌或未来轨迹。

这是借鉴[RLOO留一回报基线](https://aclanthology.org/2024.acl-long.662/)的麻将适配，保留[PPO裁剪目标](https://arxiv.org/abs/1707.06347)和旧策略KL约束，不等同于论文的完整算法。本轮没有证明优于critic方法，效果以新的配对开发和独立确认判断。

## 预算与更新

| 项目 | 预设值 |
| --- | --- |
| 每批轨迹 | 4个牌山流×4个座位×2版本=32场完整东风，16个比较组 |
| 最多批次 | 2批新轨迹，共64场；同一初始局面版本配对，不能算独立牌山 |
| 每批优化 | 16次，minibatch256；记录实际样本使用量，批末再洗牌继续使用 |
| 总更新上限 | 32次；达到门槛可提前结束 |
| 保存 / 开发验证 | 每4次保存；每8次做64场开发对局，含批内第8次验证 |
| Actor学习率 | 2e-5，原为5e-6 |
| 均匀探索 | 约束集合内15%，原为5% |
| PPO clip / KL惩罚 / 熵系数 | 0.1 / 1.0 / 0.001 |
| 硬KL上限 | 训练状态的平均旧策略KL超过0.01则回滚该批并停止 |
| 时间 | 训练和开发最多45分钟；Slurm单卡申请60分钟，预留预检和加载 |

每批至少需要4个最终回报不同的比较组，否则停止并分析信号不足。完整终局回报仍不能精确归因到某一步动作；配对只控制一部分初始条件差异，不是解出了麻将的信用分配问题。

与前轮相比，独立起始局面数量因每组两个版本而减少，这是相同轨迹预算下控制初始难度的代价。学习率、探索和基线同时改变，是组合试验；不能把收益或失败归因于某一个改动。

## 阶段目标与停止

先测固定监督旧模型在新开发牌山上的64场东风基线。候选和旧模型都面对同样三个规则基线，使用相同牌山和座位，采用相同原生推理与约束规则。旧模型也不使用探索。

- 开发目标：平均净得点不小于0，并且比同批旧模型至少高1000点/场，取较高门槛。排名只作诊断。
- 更新8：完整64场验证；达标即冻结并停止训练，否则只在无明显退化时继续。
- 更新16：较旧模型增加不足250点/场，立即停止；达到完整目标则进入确认。
- 更新24/32：继续相同验证，连续两次不刷新平均净得点最好值则停止；更新32仍未达目标也结束。
- 任意验证若平均净得点比旧模型下降至少1000点，立即停止。不因动作变化较少而自动放宽门槛或延长预算。

无有效比较组、非有限损失/梯度、冻结层或禁用critic收到梯度、原生概率重放不一致、参考权重变化和时间超限，也会停止或报错。已经结束的目录不可直接重启覆盖。

## 种子、对手及独立确认

实际引擎种子统一为逻辑ID左移32位（`spaced-v1`）。训练逻辑ID为2101000至2101007，开发为2202000至2202015，确认保留2302000至2302127，三者隔离且不同于此前试验。版本只改变策略采样种子，不改变引擎种子。

训练一半组面对三个规则基线，另一半组面对一个冻结旧模型与两个规则基线，组内两版本的对手一致。开发的16个牌山流各换座4次，按流分组统计，不把64场当作64个独立样本。反复查看开发数据仅用于筛查。

开发首次达标即冻结唯一检查点，自动进行独立确认：候选与旧模型各512场，128个新牌山流，不更新参数或重新选模。确认须同时满足平均净得点不为负、比旧模型至少多1000点/场、按流聚类的配对净得点差95%区间下界大于0。未通过则停止；通过也不会自动替换默认推荐策略。
