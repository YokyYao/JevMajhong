# 降低评分头自由度，先检查得分信号能否泛化

2026-10-30。固定增幅不再作为续训否决线；当前问题是开发提升尚未在独立牌山重现。保留的排序更新6在全新128个牌山、每模型512场完整东风中，净得点1123.83，原2000步模型1163.28，相差-39.45点，配对95%区间[-436.70,357.79]。不能确认提高，也不能确认退步。逐场审计和实际推荐CLI一致性检查均通过，默认策略未替换。

## 原因假设与本轮改变

两份唯一的单决策缓存共2560个状态，只有250个非零终局分差；原评分头却更新524800个参数。数据中的得分信号可能不足以约束这么多参数。这是待检验的解释，不是已经证明的根因。

本轮回到原2000步模型作为固定先验。把该模型的256维query与key逐维乘积作为动作特征，对替换动作与冻结对照动作取差，直接回归完整东风终局分差/1000。只拟合256个系数，不拟合截距、不裁剪正负得分，不加入名次奖励。两份缓存的冻结后续策略不同，因此目标是这两个冻结策略数据分布下的配对分差，不能称为新模型自身的精确Q值。

复用3501的512个状态与3901第一批的2048个状态。排除未改变动作的零特征提案，保留改变动作后仍然零分差的样本，预计911个动作对、250个非零标签、96个独立训练牌山。旧排序缓存与第一份完全相同，不能重复加入。逐项检查源代码、模型和冻结LoRA/tokenizer指纹、行为概率、动作、回报及分差归属；这里没有新增训练仿真。

## 有界拟合与后续对局

按整副牌山分成5折，所有座位和提案同进同出，固定划分种子2026103003。岭回归系数从0.001/0.01/0.1/1/10选择，比较留出均方误差与预测分差恒为0的基线。若全部无法改善，停止该拟合配方，继续分析特征或采样方式；不能把训练误差下降当成进步。

若存在预测信号，将分值校正精确折叠到原query各行缩放，key和底座保持冻结。预设校正强度0.25/0.5/1，限制各query行相对改动不超过25%，缓存上的15%均匀混合策略平均KL不超过0.01；必要时逐次减半。相同权重去重，没有实际缓存贪心动作变化的版本不进入对局。校正后的动作偏好仍需完整对局检验。

开发4302000至4302063，64个全新牌山、各换座4次，三个规则对手、完整四人东风；各候选与原模型在相同牌山比较净得点。保留完整开发中最高正向候选，平分取较早预设强度。小幅正提升可以支持后续验证，不要求达到250/500点。

若选出候选，固定后在未接触的4402000至4402127进行一次独立确认，双方各512场，对照原2000步模型。可靠改善的证据为按牌山聚类的配对95%区间下界大于0、候选平均净得点非负；500点仅为期望目标。若区间含0，不自动丢弃正向候选，也不宣布已经变强；根据效应和不确定性预先设计下一批新数据或复验。

先执行拟合和分组交叉验证，再决定是否启动开发对局。主模块`diagonal_value.py`，训练入口`scripts/train_diagonal_value.py`，配置`head-rl-diagonal-value.json`。只公开代码、配置和Markdown汇总；逐场、缓存、拟合系数、审计明细及新权重均留本地。

## 拟合已完成，进入预设开发检查

作业255166完成；两份数据的全部2560个状态校验通过，911个变更动作对、250个非零分差、96个独立牌山，与预期一致。5折按整副牌山留出，最佳均方误差17.420880，对照恒预测0为17.442931，仅改善约0.1264%。这是很弱的训练可预测性信号，不能据此称模型得分提高。
