# 四人东风净得点奖励试验

**执行结果：已完成16次更新并按无进展条件自动停止。旧模型平均净得点+2068.75，更新8和16均为+2084.375，仅增加15.625点/场；未达到阶段或最终目标，未进入独立确认。详见[结果和逐场审计](../reports/2026-10-29-score-east/README.md)。以下保留启动前的方案，门槛未因结果修改。**

本轮测试用户选择的得分目标：最大化完整四人东风的平均净得点。新建试验，从监督训练第2000步初始化；此前按用户要求停止的前二率试验保持停止，不继承其第8次强化学习权重。本方案及门槛在启动前固定。

## 奖励与模型

```text
reward = (东风整场最终点数 - 25000) / 1000
```

25000为RiichiEnv默认雀魂四人规则的起始点数。终局35000点奖励+10，15000点奖励-10，25000点奖励0。奖励有正有负，不截断、不取tanh，不加名次、前二、和牌次数、单手牌型打点或向听奖励。固定除以1000仅改变尺度，不改变期望净得点的优化目标。和牌收入及放铳、被自摸等失分都体现在最终点数里。

环境为RiichiEnv 0.4.11，`4p-red-east`，`GameRule.default_mjsoul()`。按引擎的连庄和延长规则自然结束，不强制四局截断。使用相同玩家可见状态、合法动作和牌效防守约束。冻结Qwen与所有LoRA，仅训练524800参数的pointer评分头和独立价值预测器。

价值预测器改为无界线性输出，可预测负数或大于1的净得点回报；保留二元目标试验的sigmoid路径以便复现。完整终局回报gamma=1，优势为回报减去采样时价值估计，并在该批轨迹上标准化。PPO、KL及探索设置保持与前二率东风试验一致。

## 阶段目标与预算

主要指标是原始点数单位的平均净得点，不把它显示成百分比。一位率、前二率、平均顺位和末位率只作诊断，不用作奖励或本轮选模门槛。

| 项目 | 预设值 |
| --- | --- |
| 固定旧模型 | `runs/semantic-2026-freegpu/checkpoints/step-002000` |
| 开发基线及每次验证 | 同批64场，16个隔离牌山流各换座4次 |
| 目标 | 平均净得点比旧模型至少增加1000点/场，且平均净得点不小于0；取较高门槛 |
| 更新预算 | 最多2个阶段，每阶段8次优化器更新，共16次 |
| 新训练轨迹 | 每阶段8个新牌山流、32场完整东风，共最多64场 |
| 保存 / 验证 | 每4次保存，每8次做64场正式开发验证 |
| 学习率 | actor 5e-6，critic 1e-4 |
| PPO clip / KL惩罚 / 熵系数 | 0.1 / 1.0 / 0.001 |
| minibatch / 均匀探索 | 256 / 5%（仅共同约束集合内） |
| 时间上限 | 训练及开发40分钟；单卡Slurm申请55分钟，预留加载和硬件检查时间 |

更新0先保存初始化并完成旧模型64场东风基线，随后采集真实训练对局。更新8验证：若目标达到，冻结检查点并停止训练，进入独立确认；若平均净得点比旧模型低至少1000点，立即停止。其余情况仅允许再做一个阶段。

更新16验证：较旧模型提升不足250点/场则判无早期进展；提升250至不足1000点但仍未达到完整目标，也结束该配方，不延长。另保留连续两次未刷新平均净得点最好值的停止规则。以上为控制成本的工程筛查，不能当作统计显著性结论。

任何阶段若完整训练轨迹的平均旧策略KL超过0.01，则回滚该阶段并停止；无回报变化、非有限损失/梯度、冻结层收到梯度或推理特征不一致也会停止或报错。原权重指纹在结束时核对，已结束目录禁止直接重启覆盖。

## 对手与数据隔离

训练一半对局面对三个规则基线，另一半面对一个冻结旧模型加两个规则基线。只更新候选玩家。开发和确认都让候选与旧模型分别面对同样三个规则基线，比较相同牌山和座位上的净得点差。

全部使用修正后的 `spaced-v1`：引擎种子为逻辑ID左移32位，避免相邻比赛复用移位牌山流。

- 训练逻辑ID：1801000至1801015，按阶段使用，每个换座四次。
- 开发逻辑ID：1902000至1902015，固定且重复查看。
- 独立确认保留逻辑ID：2002000至2002127。

三组不重叠，也不复用前二率试验的训练和验证流。同一流的四个座位按一个分组做统计，不能视为四个独立样本。当前试验不是单变量消融：目标改变后价值预测器必须适配有符号回报，且使用了新的种子和更短预算。结论仅限这套配方是否改善固定规则对手下的净得点。

## 独立确认与结论

开发首次达标时只冻结这一个检查点。自动提交一次确认，旧模型和候选各512场，共128个新牌山流，不再训练或重选检查点。确认通过须满足：

1. 候选平均净得点不小于0，且比旧模型至少多1000点/场。
2. 按独立牌山流计算的配对净得点差95%区间下界大于0。

确认不达标则停止配方，不替换默认策略。排名变化会一并披露，即使净得点提高也不宣称一位率、前二率或真实雀魂段位收益必然提高。反复查看的64场开发结果只作筛查，独立确认才用于本轮收益判断。
