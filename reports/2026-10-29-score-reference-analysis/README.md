# 从RLOO试验到冻结参考对照

上一轮已按无早期进展条件停在16次更新。同批64场开发对局里，旧模型平均净得点-634.375，更新8为-643.75，更新16为-710.9375；最终相对差为-76.5625点/场，没有达到原目标，没有进入独立确认。完整原结果见[previous-result.json](previous-result.json)。

训练32场，构成16个同牌山比较组，全部有回报差。2611个状态累计使用3891次，约1.49次/状态，评分头确实改变；更新16的贪心动作变化14/2611，约0.54%。说明采样和基线链路已经有效运行，但没有形成开发净得点收益。它不能证明RLOO或得分奖励普遍无效。

下一轮重点处理两个可检验假设：更合适的更新幅度，以及用确定性冻结旧模型对照替代另一条随机候选的基线。对照每组新增一场模拟，直接测量相同起始条件下的候选减旧模型回报，代价是额外32场完整东风。

开训前在旧训练状态上做了[学习率探测](calibration.json)：1e-4时平均KL0.001589、贪心动作变化2.22%；原2e-5在相同探测下为0.000293和0.46%。探测未使用开发/确认数据，临时更新后权重全部丢弃。相较只根据先前损失猜测，这提供了调整步幅的依据，但不能据此宣称会提高真实得分。

原先的1000点目标保留为原试验结论。新试验在启动前改设为相对旧模型每场增加500点且净得点不为负，第16次提升不足100点即停，上限24次。具体控制变量、预算、KL收缩和独立确认条件见[新训练方案](../../plans/score-east-reference.md)。
