# 东风终局得分预测拟合完成，完整对局已开始

96组新TRAIN牌山的1536条单动作反事实标签已完成采集和拟合。按整牌山分组的四折验证，最佳ridge系数α=0.1，分差预测MSE为81.34783，零预测为82.32907，下降约1.19%。这只描述动作分差预测误差，**尚无完整东风净得点提升结论**。

## 数据、目标和模型

每个牌山运行四个座位，每座冻结教师控制轨迹，再随机选择四个反应位置，各改为一个不同于教师的合法吃/碰/跳过动作，随后按冻结策略打完整场。控制384场、实际替代分支1536场，最终1536条标签全部真正改变动作。效率、混合、强对手组各512条标签；每场完整账本核对，精确前缀与合法动作顺序核对通过。

教师是当前保留的第二阶段鸣牌＋旧B普通决策组合。奖励仅为分支终局分数减控制终局分数，除1000作数值缩放；不加入吃碰、番数、排名固定奖励。输入为第二阶段自己的256维动作表征和34维公开局面特征，拟合290维线性价值层；Qwen底座、LoRA和原指针头没有更新。这一路与另行完成的200步LoRA新比赛续训不同。

四折把一个逻辑牌山的全部座位和分支留在同一折；每折72个训练牌山、24个留出牌山、384条留出标签。同动作的已知零差标签没有进入本次拟合，避免稀释MSE。封存真人test未打开。

预测RMSE约9019.30点，零预测约9073.54点；单动作可能改变后续整场路径，标签方差仍很大。验证用于选正则和判断是否值得试完整对局，不证明策略优于教师。相较早期32牌山、265条改变动作标签的失败试验，本轮同时改变了冻结教师、对手覆盖和数据量，不能把变化单独归因于加数据。

## 已实际衔接的原生评估

部署到模拟器前，20条不同TRAIN请求的教师概率与采样时最大误差0，CPU/原生动作价值最大差约7.62e−8千点、选择一致；6条普通请求概率不变。动作差按与拟合器一致的float32规则构造，教师相对价值精确为0，完全中性时保留教师；没有另加手工奖励或正收益幅度阈值。

768场新牌山开发已实际开始：保留第二阶段组合与新预测器各384场，四座、三组对手，使用预留10220000–10220031。旧B普通决策、强组对手、自动和牌及弃牌约束相同。只跑两个比较臂，不重复旧B第三臂。

只有完整开发审计后相对教师均值为正，才在10230000–10230127的128个独立牌山做3072场两臂确认；区间跨零不宣称稳定，也没有固定+250/+500分门槛。训练标签只估计一次干预后继续按教师行动的结果，而实际策略会连续改动作，因此必须通过完整对局测量分布变化后的收益。
