# JevAny 麻将模型本轮训练结果总结

**统计方法更正：本页对局使用连续原始种子，局级牌山流重叠，原独立样本假设和对应置信区间解释撤回。原始分数及比例保留为该批牌山的历史描述；新强度判断需使用隔离种子重新评估。见[种子独立性更正](../seed-independence-erratum.md)。**

2026 年 10 月 28 日完成的这一轮训练，已跑满 2000 步，完成 1024 条验证决策及两组各 128 场的四人半庄仿真。最终模型能在 67.68% 的验证决策上复现真人选择；加入牌效与防守约束后，一位率达到 31.25%，平均顺位为 2.328，表现优于本轮纯模型。**约束版本有继续研究的价值，但一位率提升的统计证据仍不足，尚未通过默认策略替换门槛。**

## 训练配置和数据

本项目使用开源 JevAny 将 Qwen3.5-0.8B 改造成合法动作评分器：冻结底座原有权重，训练 rank 16 的 LoRA 和 256 维动作评分头，合计约 1130 万个可训练参数。目标是在给定玩家可见局面和合法动作候选时，提高牌谱真人实际选择动作的概率；损失为交叉熵。此轮没有使用自博弈、PPO 或终局顺位奖励。

| 配置 | 本轮取值 |
| --- | --- |
| 底座 | `Qwen/Qwen3.5-0.8B` |
| 底座版本 | `2fc06364715b967f1860aea9cf38778875588b17` |
| JevAny 版本 | `c740121a4532592b09b6272104d5f29a94c232e5` |
| 初始化 | 2019 年牌谱预热权重；预热呈现 1024 条样本、128 个优化器步 |
| 本轮主训练 | 32000 条决策，一个 epoch，2000 个优化器步 |
| 有效 batch 和学习率 | 16；0.00005 |
| 计算 | 单卡 RTX 5000 Ada，BF16 |
| 上下文限制 | state 4096，branch 8192，packed 8192 tokens |
| 训练准入 | 32000 条全部准入，无截断或上下文拒绝 |

2026 年数据来自 [`nikketryhard/tenhou-houou-mjai`](https://huggingface.co/datasets/nikketryhard/tenhou-houou-mjai) 的 `majsoul-throne-2026.tar`，来源版本固定为 `6450bb584cef43ede3b514df48e301a832c6818b`。使用 RiichiEnv 0.4.11 的雀魂规则重放，按整场比赛分组，训练、验证和测试比赛 ID 互不重合。

| 数据划分 | 决策数 | 比赛数 | 本轮用途 |
| --- | ---: | ---: | --- |
| 训练集 | 32000 | 1000 | 更新参数 |
| 验证集 | 1024 | 32 | 定期监测和最终完整验证 |
| 测试集 | 1024 | 32 | 保留，本轮未做推理评测或选模 |

输入使用自己的手牌、公开弃牌与副露、分数、场况以及向听数、有效进张和现物等信息，不使用对手暗手或未来牌山。重放准备阶段因可见牌数量不一致而排除了 126 场比赛；这可能影响含杠局面的覆盖，后续应审查这些排除样本。

## 验证结果

完整验证集共 1024 条决策，模型的最高概率动作与真人一致 **693 次，一致率 67.68%，平均负对数似然 NLL 为 0.87549**。推理前剥离答案标签和元数据，使用与训练一致的上下文限制。全部样本均有多个合法候选，不包含只有一个选项的必选样本。

整体一致率会受到动作类型分布影响。按真人目标动作拆分，真正的弃牌选择一致率为 **57.79%**，明显低于总体数值；因此不能把 67.68% 表述成纯弃牌准确率，更不能表述成胜率。

| 真人目标动作 | 样本数 | 一致数 | 一致率 |
| --- | ---: | ---: | ---: |
| 弃牌 | 770 | 445 | 57.79% |
| 跳过 | 199 | 199 | 100.00% |
| 吃 | 17 | 17 | 100.00% |
| 碰 | 17 | 17 | 100.00% |
| 立直 | 9 | 5 | 55.56% |
| 和牌 | 10 | 10 | 100.00% |
| 加杠 | 2 | 0 | 0.00% |

吃、碰、和牌和杠类样本数量很少，这些分项不能代表稳定的泛化能力。真人选择也不是最优动作的唯一标准，一致率衡量的是模仿效果。

训练期间对固定 128 条验证子集进行监测，每场验证比赛按 ID 哈希选择 4 条，最终完整验证仍来自同一批 32 场比赛，因此是开发验证，不是新的独立测试。

| 步数 | 子集一致率 | 子集 NLL |
| --- | ---: | ---: |
| 600 | 57.81% | 1.04562 |
| 800 | 62.50% | 1.00974 |
| 1000 | 61.72% | 1.09296 |
| 1200 | 64.06% | 0.99708 |
| 1400 | 64.84% | 0.98028 |
| 1600 | 60.94% | 1.02437 |
| 1800 | 64.06% | 0.96850 |
| 2000 | 64.84% | 0.97818 |

从第 600 步到第 2000 步，同一子集一致率上升 7.03 个百分点，NLL 下降约 0.067；后半程存在波动，尚不能仅据此判断稳定收敛或过拟合。监测器按 NLL 记录的最佳检查点为第 1800 步，本轮对局评估按计划使用最终第 2000 步，没有把第 1800 步称为实战最优模型。2019 年预热模型的历史验证使用不同样本，不能直接与本轮完整验证作提升幅度比较。

## 四人仿真结果

环境为 RiichiEnv 的雀魂规则四人赤牌半庄 `4p-red-half`。每桌一个候选玩家、三个相同的牌效防守规则机器人。规则基线根据向听、进张和立直威胁下的现物等信息决策；两种候选均在有和牌动作时直接和牌。约束版本进一步限制弃牌不能劣于基线选项的向听水平，并在触发弃和条件时限制现物风险，再在符合条件的候选中按模型概率选择。

评估使用种子 710000 至 710031，每个种子轮换四个座位，每种候选得到 128 场结果。每条候选结果配有同种子、同座位、四人全为基线的对照；两种候选共用这批对照。固定种子固定初始化，策略改变后摸打轨迹会分叉。四次换座结果按种子聚类计算区间，独立样本单位是 **32 个种子**，不是 128 个完全独立牌山。

| 指标 | 规则基线 | 纯模型 | 牌效防守约束模型 |
| --- | ---: | ---: | ---: |
| 一位率 | 25.00% | 25.00% | **31.25%** |
| 一位次数 | 32/128 | 32/128 | 40/128 |
| 平均顺位，越低越好 | 2.500 | 2.445 | **2.328** |
| 末位率 | 25.00% | **14.06%** | 17.19% |
| 和牌次数除以局数 | 17.84% | 16.18% | **20.91%** |
| 放铳次数除以局数 | 12.43% | 8.23% | **6.87%** |
| 平均终局原始点数 | 25000.00 | 27132.81 | **28849.22** |
| 相对起始 25000 点的平均净得点 | 0.00 | +2132.81 | **+3849.22** |

一位率指整场半庄结束、按最终结算顺位排名第一的比例，不是最先出牌或最先和牌的比例。和牌、放铳指标按各策略实际经历的局数计算，分母分别为基线 1480 局、纯模型 1434 局、约束模型 1368 局。终局点数直接取环境的原始点数，不含顺位奖励换算；得点与最终顺位同时报告，不能用一次先和牌代替整场得点表现。基线的 25% 一位率来自四个相同机器人在每个种子上轮换全部座位，不是对真人胜率的估计。

| 与规则基线的配对差值 | 纯模型 | 约束模型 |
| --- | ---: | ---: |
| 平均顺位差 | -0.05469 | -0.17188 |
| 顺位差的 95% 区间 | [-0.24449, 0.13512] | [-0.31196, -0.03179] |
| 一位率差 | 0.00 个百分点 | +6.25 个百分点 |
| 一位率差的 97.5% 区间 | [-9.89, 9.89] 个百分点 | [-2.91, 15.41] 个百分点 |

上述区间是当时按种子内配对差值和 Student t 方法计算的历史输出。后续发现局级牌山流重叠，相关独立性假设不成立，因此这些区间不再作为有效的95%或97.5%置信证据，不能据其宣称改善。约束版本在本批对局的末位率比纯模型高3.13个百分点，点估计也不是所有指标都更好。

## 效果判断和策略选择

这轮训练完成了从牌谱监督到合法动作评分、完整验证和对局筛选的流程。纯模型并未显示明确的一位率优势；约束版本在本轮样本上的平均顺位、和牌和放铳指标较好，但这些改善属于模型与规则共同构成的策略，不能全部归因于神经网络。

预设替换门槛要求至少 32 个种子、一位率差的 97.5% 区间下界大于零、顺位差的 95% 区间上界不大于零，以及末位率不超过 25%。两个候选都未通过一位率门槛，`selection.json` 因此保留 `active_policy: efficiency`，没有自动启用模型。

本轮只针对一个规则对手组合、一个训练随机种子完成筛选，不能推断雀魂段位，也不能推断对真人或成熟麻将 AI 的效果。尚未在同一评估配置下对比未微调底座和预热模型，无法量化本轮训练本身带来的实战增益。下一轮优先冻结约束策略，在新的、更大规模独立种子集上确认效果，并加入不同风格对手；随后扩充弃牌、立直和杠等决策数据，再比较监督训练与基于终局回报的训练。增加 GPU 或继续降低模仿损失本身不能保证一位率提升。
