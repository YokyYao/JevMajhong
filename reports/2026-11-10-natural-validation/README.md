# 新自然牌谱验证诊断

新训练/验证特征准备已完成，30720 次原生概率校验全部通过，冻结参考文件未改变。随后固定旧模型、call150、trust15，完成新 validation 的 2048 条决策、65 场比赛诊断。三个视图共用相同决策，不是6144个独立案例。test 的2048条决策未编码或推理。此次诊断没有训练模型或重新选择正在独立复验的 trust15。

## 完整动作的精确率与召回

“完整吃牌”要求具体 consumed 组合与专家一致；只选对吃牌类型不算完整命中。验证集专家目标为吃121、碰202、跳过1725。

| 视图 | 吃牌精确率 call150 → trust15 | 吃牌召回率 | 碰牌精确率 | 碰牌召回率 |
|---|---|---|---|---|
| 原生 | 15.26% → 23.76% | 23.97% → 19.83% | 55.07% → 56.94% | 61.88% → 60.89% |
| 截图，元数据已确认 | 13.29% → 14.47% | 36.36% → 19.01% | 46.86% → 52.53% | 70.30% → 66.83% |
| 截图，元数据未知 | 12.84% → 19.64% | 11.57% → 9.09% | 58.25% → 58.54% | 59.41% → 59.41% |

旧模型在这2048条新反应的三个视图均全部跳过，不能据其84.23%的整体一致率认定它已解决鸣牌。trust15 减少了与专家不一致的鸣牌，也漏掉了一些专家鸣牌，尤其已确认截图视图的吃牌召回下降较多。三视图平均 NLL 从 call150 的0.54408降至0.50167；这些仍是开发模仿指标，不是和牌率、最优动作证明或真人得点证据。

原生输入下，call150 推荐417次鸣牌，154次与专家完整动作一致，263次不一致；trust15 推荐317次，147次一致、170次不一致。专家鸣牌总数323次。频率已接近，具体局面的选择仍有较大差距。专家可能只选择了多个合理动作之一，“不一致”不等于已证明该动作战略错误。

## 对下一轮的启示

这些结果提示单纯控制整体鸣牌频率仍有局限，需要更好地区分应吃碰的具体牌局。下一项控制试验用新8192条自然分布反应继续训练相同 query，保留学习率与教师KL；采用更大且独立的新validation，并将防退化规则明确到每个视图的完整动作召回。训练数据、分布和选模保护同时改变，不能把未来差异简单归因于数据量。

这项并行试验基于已完整结束的新validation诊断，未查看或使用3072场独立复验的部分得分；后者仍评估原trust15。新候选使用另一批开发牌山，旧test和新test均不用于本次训练或选模。参见[新自然数据训练方案](../../plans/call-natural-query-20261110.md)。
