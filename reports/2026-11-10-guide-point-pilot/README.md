# 攻略特征与单次鸣牌得分标签：首批结果

作业289199完成32个新训练牌山、四个座位、每座四次配对采样，共512条标签，其中265条实际替换了教师动作。每个控制和分支的得分分解与终局净得点吻合，原生指针特征在采样期间持续核对，未打开封存人类test。

按照预先固定的整牌山四折验证，零差值预测器MSE为91.0497736，290维岭回归的最佳MSE为91.1340675（alpha100，单位为千点平方），没有超过零预测。其他较小正则也未改善。按原方案记录point_predictor_not_improved，不保存候选权重、不做昂贵开发对局、不部署。开发入口已实际执行并正常产生跳过记录，9110000系列仍未用于游戏；没有净得点或胜率改善证据。

新增原生价值推理路由及三组完整对局审计代码，通过4项接口机制测试和3项汇总审计测试；由于没有合格候选，还未进行GPU价值推理核对或强度对局。代码准备好不代表该学习方法有效。

当前结果说明此回归配方尚未显示得分差预测的泛化收益，不直接等同于攻略特征没有价值。下一步应检查标签方差、动作/局面覆盖、对手分布及重复样本相关性，再确定采样改进。继续保持用户指定的整场净得点目标。源码、配置与本摘要公开，原文缓存、真人牌谱、逐场记录、指针特征等均私有。
