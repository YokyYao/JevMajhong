# 均衡正例能学会吃碰，但带来明显鸣牌偏向

训练291206及CPU审计/固定校正291255均已完成。自然、均衡两组各512条TRAIN、4轮、128步、2048次请求曝光；按各自TRAIN NLL分别选第80步和128步。两组从完全相同的第二阶段LoRA/头初始化，底座冻结，最大预算、学习率、随机seed相同，实际曝光预算也相同。数据子集不同：自然组门清吃26例、均衡128例，不能把两组TRAIN命中分母当作相同测试集。

完整CPU审计逐条重算两组各9次检查、各17280条预测，合计34560条；SDK NLL、分类指标、训练游标、选模和完整检查点核对通过。每组实际512条全部准入、拒绝0。第0步原验证与相同父模型一致。原始数据、预测和新权重保持私有。

同类型但不同组合不算精确命中。“专家跳过时选择吃碰”是与专家不一致的诊断，不意味着每次都违反规则或必然降低净得点。此处没有运行完整对局，不报告得分收益或真人胜率。该验证集已用于多轮诊断，不是新的独立test。

各自TRAIN上，自然组选中模型的门清吃4/26、门清碰11/17；均衡组为98/128、120/128。均衡模型在验证门清吃碰上也明显改变，但专家跳过样本的不一致大幅增加。结果支持现有rank16 LoRA能学到相关判断，不能把此前低召回直接归因于LoRA完全学不会；也没有证明容量不是其他限制。

## 固定抽样校正没有同时保留两类判断

校正权重在完整训练结束前登记，严格由第四阶段TRAIN池/均衡抽样类别数量之比计算，没有阈值拟合或验证集参数搜索。它只分析缓存概率，没有修改模型或服务。对均衡TRAIN，校正将专家跳过时吃碰51/128降至1/128，但门清吃98/128降至7/128；validation同样由大量吃碰回到偏向跳过。训练概率是否满足抽样条件分布假设尚未证实，且原第四阶段池本身不是所有真实对局的总体分布。

因此不将这两个拟合模型或其校正直接作为效果候选。第二阶段继续保留；新实验改为[训练时显式考虑已知包含比例的选择似然](../../plans/sampling-likelihood-20261111.md)，验证和推理使用原始概率，再做新牌山完整东风净得点对照。当前结果没有证明这种新损失一定有效。
