# 训练回报基线诊断：固定差值增加了残差波动

本分析仅使用已完成训练集，不读取开发或独立确认结果。每次拟合排除当前整个牌山的所有座位和采样版本。

| 训练数据 | 固定参考残差RMS | 留出校准RMS | 按决策数加权：固定/校准 |
| --- | ---: | ---: | ---: |
| 8个流、64场采样 | 15.0617 | 9.8196 | 16.2400 / 10.5926 |
| 32个流、256场采样 | 13.3719 | 8.8672 | 13.6388 / 9.1541 |

这些是回报残差，单位1000点，不是模型平均净得点，也不直接度量完整策略梯度方差或实战能力。32流训练回报的候选/参考相关性约0.355，跨流估计系数0.233至0.301；候选均值比贪心参考低4.9914回报单位。参考直接以系数1相减，同时带来偏移和较大残差，值得检验校准。

8流数据较少，校准RMS9.8196还略高于排除当前牌山后使用常数均值的9.1226，不能把校准说成普遍最优。32流数据的相应常数基线RMS为9.4059，校准降至8.8672。当前发现支持新实验，尚不能证明更高得分。
