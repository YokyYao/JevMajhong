# 净得点试验的原因分析

本分析在启动改进试验前完成。上一轮结果见[原报告](../2026-10-29-score-east/README.md)，完整特征轨迹和检查点仍保留在 `runs/head-rl-score-east/`。[补充诊断JSON](diagnostics.json)来自对原5090个状态及第16次评分头的CPU重放。

## 已验证的观察

1. 奖励实现正确。64场训练、5090个状态的回报逐项等于终局净得点除以1000，既有正数也有负数；评分头参数确实更新，Qwen和LoRA指纹未变。
2. 价值预测没有形成有用的局面区分。第二阶段回报从-26到+19.5，预测只有约-1.13至-1.08；训练内MSE55.90，高于恒预测0的54.11。该线性基线在这一批数据上表现接近常数。这是训练内诊断，不能断言它是唯一失败原因。
3. 样本利用和策略变化都有限。每批只做8次、每次256个状态，合计4096次状态使用，少于采集的5090个状态，约0.805次/状态。原5090个状态在更新16后只有10个贪心动作改变，约0.196%。
4. 硬KL上限没有触发。重放后平均旧策略KL为0.00000673，最大单状态约0.00007197；硬停止阈值是完整轨迹平均0.01。小更新幅度不能归因于已经撞上该硬上限；软惩罚的影响仍未单独消融。
5. 排除了一个具体数值嫌疑。5090个状态中，合法约束集合的概率全部下溢为0的次数为0；从全softmax概率取最大与直接从约束集合logit取最大，选择差异也是0。没有证据把本轮结果归因于这个问题，因此保留原推理口径。

平均最大约束动作概率约0.701，平均前两名logit差约3.17，策略并非完全确定性。64场开发对局只有一场第三名多1000点，其余终局不变，说明当前小幅更新没有转化成足够的对局变化；不能由此断言旧模型已达到上限。

## 改进方向与边界

下一轮保留终局净得点奖励，移除表现较弱的学习式critic，改用同一牌山、同一座位下独立探索版本的留一终局回报作为基线。固定牌山控制起手难度，其他版本的回报不依赖本版本动作。该思路借鉴[REINFORCE Leave-One-Out](https://aclanthology.org/2024.acl-long.662/)，本项目继续采用PPO裁剪更新，并非复现该论文的LLM实验；论文结果不保证麻将收益。

同时将每批优化预算8次改为16次、actor学习率5e-6改为2e-5、约束集合内均匀探索5%改为15%。保留原硬KL阈值和实战退化停止，监测样本使用量、配对回报差、裁剪比例与真实动作变化。这是组合修正的实用试验，不是单变量因果实验。

具体预算、数据隔离和开训前门槛见[改进方案](../../plans/score-east-rloo.md)。本轮不以训练损失下降、动作变化增多或组内得分提高代替独立对局收益。
