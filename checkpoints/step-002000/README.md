# 第一轮最终检查点 第 2000 步

这是第一轮主训练完成 2000/2000 步后的完整检查点，与[第一轮结果报告](../../reports/2026-10-28-training/README.md)评估的模型一致。它包含 LoRA、pointer 动作评分头、tokenizer，以及优化器、调度器和随机状态；冻结的 Qwen 底座需要按固定版本另行下载。

## 模型与训练

- 底座：`Qwen/Qwen3.5-0.8B`，版本 `2fc06364715b967f1860aea9cf38778875588b17`。
- 框架：JevAny，版本 `c740121a4532592b09b6272104d5f29a94c232e5`。
- 训练：监督模仿学习，LoRA rank 16，256 维 pointer 头，BF16，约 1130 万可训练参数。
- 主阶段数据：2026 年雀魂王座牌谱，32000 条决策，1000 场训练比赛，一个 epoch，2000 个优化器步。
- 主阶段参数：batch 16、学习率 0.00005、随机种子 4242、单 GPU。
- 初始化：2019 年王座牌谱预热权重；此前呈现过 1024 条预热请求。

## 下载与还原

完整检查点有 9 个文件；压缩归档共 130863958 字节，约 124.80 MiB，拆成 32 个分片。下载整个目录后，从仓库根目录执行：

```bash
python3 scripts/restore_checkpoint.py checkpoints/step-002000/manifest.json \
  --out runs/restored-step-002000
```

脚本先校验每个分片、完整归档及全部 9 个还原文件的 SHA-256，再生成输出目录。输出目录必须尚不存在。上传前已经完成完整还原，并逐文件确认与本地最终检查点完全相同；权重文件指纹与结果报告中的记录相同。

安装根目录说明中的环境并准备自己的合法动作请求后，可显式调用模型进行离线推荐：

```bash
.venv/bin/python recommend.py runs/restored-step-002000 your-request.json
```

该命令输出模型候选动作分数。对局中所用的牌效防守约束由 `arena.py` / `recommend_state.py --guarded` 实现，不是另一套模型权重。

本检查点已完成原定 2000 步计划。若开展第二轮训练，应在新配置中用 `init_from = "runs/restored-step-002000"` 初始化并设置新的数据、输出目录及训练计划；不要通过 `--resume` 延长原有已结束的计划。保留的训练状态用于完整归档和兼容环境下的状态检查。

## 评估结果

完整验证集 1024 条决策，整体动作一致率 67.68%，弃牌一致率 57.79%，整体 NLL 0.87549。四人半庄各评估 128 场：纯模型一位率 25.00%、平均顺位 2.445；加入牌效防守约束后，一位率 31.25%、平均顺位 2.328。一位率按整场半庄结束时的最终排名计算。纯模型、约束模型的平均终局原始点数分别为 27132.81、28849.22，起始点数为 25000；得点不包含顺位奖励换算，未用作本轮训练奖励。

约束版本的一位率提升置信区间仍包含零，未通过预设替换门槛，默认策略继续使用规则基线。动作分数不是和牌率，也不能据此推断雀魂段位。完整指标、对照、置信区间与局限见[结果报告](../../reports/2026-10-28-training/README.md)；本目录另有机器可读的 [评估摘要](evaluation-summary.json)。

不包含原始牌谱、Qwen 冻结底座、用户凭据或客户端接入。第三方署名及各自许可见根目录 `THIRD_PARTY_NOTICES.txt`。
