# Main training checkpoint, step 600

主阶段600/2000步的固定快照，训练并未在600步停止。本检查点可用于离线推理及兼容环境下的单卡训练接续。

- 底座：`Qwen/Qwen3.5-0.8B`，版本`2fc06364715b967f1860aea9cf38778875588b17`，需单独下载。
- 框架：JevAny，版本`c740121a4532592b09b6272104d5f29a94c232e5`。
- 方法：监督模仿学习，LoRA rank16加pointer动作评分头，BF16，约1130万可训练参数。
- 主阶段训练集：2026雀魂王座32000条决策、1000场比赛；本快照已处理9600次主阶段请求呈现。
- 预热：此前使用2019王座数据处理过1024次请求呈现。
- 主阶段参数：batch16、学习率5e-5、seed4242、world_size1。

## 内容与校验

完整检查点的9个文件（约157MB）压缩为约125MiB归档，再拆成32片。包括LoRA权重、pointer头、tokenizer，以及用于继续训练的优化器/调度器/随机状态。原始底座权重和训练数据不包含在内。

`manifest.json`记录每个原始文件、每个分片及完整归档的SHA-256。已在上传前执行完整还原并核对全部9个文件。不要单独解压某一片，也不要加载不完整的检查点。

从仓库根目录：

```bash
python3 scripts/restore_checkpoint.py checkpoints/step-000600/manifest.json \
  --out runs/restored-step-000600
```

安装根目录说明中的环境并准备相同数据后，恢复剩余1400个优化步：

```bash
.venv/bin/jevany train --resume runs/restored-step-000600 --out runs/resumed-step-000600
```

上游会核对训练数据指纹、模型和训练配置。保持单卡world size1及相同设备类型；模型大小、数据、LoRA设置或卡数改变时，应创建新实验，而非声称原样恢复。

## 验证状态

固定开发验证子集包含32场比赛各4个决策，共128条。第600步动作一致率57.8125%，NLL1.045618，详细摘要见`validation-summary.json`。

这些数字反映模仿牌谱动作的程度，不是和牌率、一位率或雀魂段位。当前快照没有完整测试集和正式对局牌力结论。测试集没有用于训练或挑选此快照；此快照是按上传请求时最新完整检查点确定的。

数据来源和第三方署名见仓库根目录`THIRD_PARTY_NOTICES.txt`，其中Qwen底座权重和上游项目仍适用其各自许可。
