# Existing curriculum catalog for later targeted data reuse

Build one private sidecar index over the already audited87,595 TRAIN/23,688
validation union during stage3A, in a separate finite GPU allocation. This
implements the [targeted-data reuse requirement](curriculum-targeted-data-catalog-20261123.md)
without changing the running fit or collecting another teacher baseline.

Each index entry references the immutable source file/hash, original line,
record/family identity and authoritative file partition. Source/phase, offered
operations, actual hard selections and soft-label status remain distinct.
Inherited historical split metadata is retained separately. No raw hands or
source payloads are duplicated into the index and no data becomes model input.

Compute public concealed-hand structural distances for closed no-meld13/14-tile
hands and count near-kokushi/chiitoitsu and nine-gates base-pattern support.
Triplet-rich and dragon-supported hints are explicitly not certified suuankou
or daisangen labels. Hands with melds are counted separately, not falsely
treated as open or closed without decoding meld type. These are descriptors,
not winning-yaku annotations, value labels, student results or a training recipe.

One streaming source hash, original record/group totals and cross-partition
family exclusion protect the actual index references. Reuse existing native,
tokenizer, label and data audit evidence; do not repeat those broad checks.
Count unique families per tag as well as records, because many related views
do not create independent support. Do not read the final reserved test.

Inputs, code/config and source files are immutable during execution. Outputs
and errors use a new run directory. Raw indexes stay private; publish only
code, this plan and small aggregate coverage after actual completion. There
are no model calls, parameter updates, new games or new teacher labels. Use
only the declared bounded GPU job with companion CPUs/logs/exits; no login
processing or CPU-only substitute.
