# Jev Unified WinRisk v3：修正安全收益标签

v2在192场完整开发对照及独立审核中，和牌率均值+2.296个百分点，但放铳+2.766个百分点，超过1个百分点门槛，未进入768场确认。净点−445.83/场且区间跨零，尚无稳定提升结论。本轮继续使用单一LoRA和动作头，训练目标仍为提高自己和牌率并控制放铳。

## 已核对的问题

配置奖励为自己和牌 +0.25×折扣速度 −2×放铳，净点系数0。旧标签规则却会将“自己和牌机会略降，但放铳风险下降更多、总奖励为正”的动作收益截成0。对实际3143个模拟训练位置逐一重建并匹配原标签后，发现280个动作比较受影响，涉及215个位置；修正后65个位置的最大概率标签改变。按位置为吃碰130、杠26、副露出牌25、门清出牌34；没有读取当前评估逐场内容生成标签，没有新增模拟。

这证明标签转换与配置奖励存在不一致，尚不能证明它是v2风险上升的唯一原因。新规则只在放铳概率下降且综合奖励为正时允许这种局部权衡；负收益动作继续受惩罚。它也可以推荐更安全的吃牌，没有“始终跳过鸣牌”的先验，未标注合法动作继续保持零直接监督梯度。

## 单一改动与固定条件

只修改上述215个模拟训练位置的target/label，其他训练位置、状态、菜单、ID和顺序保持不变。32768个唯一训练位置、29625个牌谱模仿位置、3143个模拟位置及所有来源/阶段系数保持v2方案。完整540条验证文件字节、标签和分组不变；原验证目标作为可比较的诊断，最终效果仍由新牌山的完整对局判断。

与v2使用同一初始化：v1明确声明的末步512实验权重，未晋级正式模型；不从v2失败后的权重继续。冻结Qwen3.5-0.8B基座，rank16、BF16、微批1、累积16，LoRA/head学习率2e-6/1e-5，种子2026111407、新优化器、固定1024步及每256步验证。只使用预先登记末步1024参加对局，不挑选旧步数补测。

奖励系数不变；牌谱/模拟损失质量75%/25%，模拟内部门清40%、吃碰30%、杠20%、副露10%，单例系数上限8，均值1，不复制或按收益方向筛选样本。一次修改一个训练因素，仍不能因两轮评估牌山不同而直接宣称因果效果。
