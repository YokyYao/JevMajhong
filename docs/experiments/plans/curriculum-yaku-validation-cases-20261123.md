# Reusable small conditional yaku benchmark: frozen v8 first

Use all92 existing validation initial source cases/45 inherited families, with
their original full walls and seat0/dealer0 context. Do not generate more test
games or rerun the established64 complete-East reference matches. This is a
new conditional capability baseline that can be cached for later candidates.
Keep all source cases, including the single initial legal-win shortcut.

Load the exact frozen v8 bundle and its original PolicyAgent execution route
from the existing registered reference. Other players are fresh stateful
Mortal actors, initialized after the same numerical runtime setup. Play each
case to the first actual hand settlement, with no hidden-world resampling or
original-history actor reuse. Own policy changes create real public histories
that the opponents follow; no private tile or intended route enters a policy
request. Preserve all failed attempts, aborts, deal-ins and alternative wins.

Report per-route source support, conditional own-win/deal-in and first-hand
net transfers, actual supported public winning yaku and initial forced wins
separately. A source route is not a required winning yaku. The narrow no-ura
scorer's unsupported cases stay explicit. Native ledgers check point/stick
consistency, not full independent scoring-engine equivalence.

These are biased source-hand outcomes against three Mortal players, not
natural Mahjong Soul win rates, complete East placement, confidence in global
strength, or proof that a forced win was learned. Old all-Mortal source wins
are descriptive provenance, not a matched comparator with implicitly identical
numerical settings. Future candidate comparisons use the same benchmark code,
walls, opponent settings and families; original v8 parameters/policy stay fixed.

One finite20-minute GPU job, companion CPUs, device check/logs/timeouts/exits;
no login inference or unmanaged workers. Model files remain unchanged. Publish
code/plan and aggregate results only; raw per-case trajectories stay private.
This does not alter3A training or register3B; final confirmation seeds stay closed.
