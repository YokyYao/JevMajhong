## 阶段目标与对局验证

1. 核查原始 base、新LoRA/动作头、零数据泄漏、全部token准入和真实参数更新。此阶段已达到。
2. 每128步检查四阶段验证，耐心3次；完整权重选定后，自动运行352例原生推理概率一致性检查，覆盖普通出牌、吃碰、三种杠和放弃杠。
3. 再次核对未消费牌山，进行8组牌山、三类对手、四座位、双方各96场，共192场开发对照，独立遍历MJAI复算支付、立直棒池、和牌/放铳、速度和终局名次。它不宣称独立重算番符。
4. 配对自身和牌率均值为正，且放铳率增幅均值≤1个百分点，才用另外32组牌山进行768场确认。确认要求和牌率95%区间下界为正及同一风险限制；失败则修改训练方案，不发布替换权重。
