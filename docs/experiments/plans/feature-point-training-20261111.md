# 从保留的Jev Call v1采集东风动作得点标签

**已完成采样和拟合，完整对局已开始：** 96个TRAIN牌山、1536条实际改变动作标签；四折MSE81.34783，零预测82.32907，约下降1.19%。20条原生价值和6条普通概率核对通过，已进入768场新牌山两臂对照，尚无净得点提升结论。见[拟合聚合报告](../results/2026-11-11-feature-point-fit/README.md)。

目标仍是完整东风终局净得点。保留Jev Call v1第200步鸣牌LoRA及动作头，普通出牌继续由Jev Discard v1负责；不会把当前Jev Call v1权重覆盖。此次先学习动作价值，不进行LoRA或底座全参数更新，不能称作Jev Call v1本体又续训了若干步。

## 为什么做这项实验

Jev Call v1相对Jev Discard v1的独立确认+1045.83点/场，区间下界为正；Jev Call v1减第一阶段同牌山确认+277.21，区间跨零。后续确实沿Jev Call v1续训过：Jev Call Reaction v1新增请求、改变reaction选模范围，完整开发减Jev Call v1−90.63；Jev Call Curriculum v1改变公开机会分层，减Jev Call v1−476.04。区间均跨零，结论是两个具体候选未显示增益，不是证明继续训练一定无效。

最近抽样似然候选[完整开发](../results/2026-11-11-sampling-likelihood-development/README.md)减Jev Discard v1−239.32，没有直接父模型对照。均衡专家动作训练可以提高吃碰召回，却会破坏跳过判断；这说明适配器能改变决策，也说明动作一致率不是主目标。不能把这些同时改变配方的实验统称为“原方案续训已经失败”。保持原配方、使用新独立比赛的短程续训，仍是需要公平比较的主线选择。

历史小规模得点回归也曾失败：旧鸣牌头、32个训练牌山、265条实际改变动作的标签，整牌山CV最佳MSE91.134，高于零预测91.050。本次同时更换为Jev Call v1冻结教师、扩大独立牌山覆盖并覆盖三组对手，是一个新假设；不能把未来变化仅归因于加数据。

## 已实现的采样与拟合

1. 三个新TRAIN牌山做GPU机制检查，循环覆盖效率、混合、强对手。先核对已打开验证中的6条鸣牌概率和6条TRAIN普通概率；所有实际鸣牌捕获还逐次比较原生概率和缓存头重算概率。
2. 正式使用96个新TRAIN牌山，每组对手32个。每个牌山跑四个座位，每座冻结控制轨迹后随机抽4个决策位置，选择一个不同于教师的合法动作并重新打完整场。最多1536条实际改变动作标签；没有鸣牌机会的轨迹不伪造标签。重复位置和同牌山样本相关性在分组中保留。
3. 分支在单次干预前精确重放并核对状态摘要和全部合法动作顺序；同一步其他玩家保持控制轨迹动作。后续采用原冻结策略和同组固定对手。标签仅为分支终局分数减控制终局分数，除1000作数值缩放；无吃碰、番数、排名或前二固定奖励。
4. 预测输入是Jev Call v1自己的q/k投影产生的256维动作特征和34维公开局面特征，拟合290维线性ridge动作差值。不得把Jev Discard v1的投影配给Jev Call v1编码。隐藏手牌/牌山只参与模拟和私有重放校验，不进入预测特征。
5. 整牌山四折CV，将所有座位与分支留在同一折，比较预测动作差的MSE与恒为零基线；没有同动作的已知零标签稀释MSE。正则候选预登记为0.001、0.01、0.1、1、10、100。CV选模仍可能乐观，只作是否值得进入新对局的诊断。

完整计分包括和牌、放铳、被自摸、流局、立直棒收支和终局结算，要求每场账本之和等于终分减25000。对手与既有原生评估相同：三名EfficiencyAgent；两名EfficiencyAgent加CallingOpponent；两名EfficiencyAgent加冻结Jev Discard v1，特殊对手位于自家下家。

## 阶段判断与后续评估

GPU机制检查没有得点优劣门槛。只有三组原生概率、普通路由、精确前缀、单次干预、完整账本和文件身份通过，正式任务才运行；每个副本更新状态，每个完整牌山原子保存私有分片和校验哈希，允许在相同冻结协议下续采。

CV未胜过零预测时，不部署、不宣称训练有效，分析标签方差、覆盖和特征后调整。CV有正向信号时，在预留32个新牌山上比较候选与Jev Call v1两个策略，Jev Discard v1仍负责两者普通决策及强组对手，无需单独第三臂；主比较为候选减Jev Call v1，不用跨牌山历史结果替代。均值正的候选再用预留128个独立牌山确认，报告区间和强对手组，不设固定+250/+500门槛。完整得点非正则保留Jev Call v1并及时换方案。具体[服务与两臂评估方案](feature-point-value-evaluation-20261111.md)在拟合完成前另行登记，原采样、奖励和标签不变。

机制检查TRAIN为10200000–10200002；正式TRAIN为10210000–10210095；开发预留10220000–10220031；独立确认预留10230000–10230127。各自与已登记历史范围检查不重叠。后两阶段尚未运行，不算已完成测试。
