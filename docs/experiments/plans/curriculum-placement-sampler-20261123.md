# 第四阶段曝光与采样实现

该实现承接 [80/20 配比提案](curriculum-placement-mix-20261123.md)，不修改已排队的配比准备作业，
不改变正在运行的 3A 或排队的 3B。实际标注尚未全部完成，第四阶段仍未启动训练。

`tools/curriculum_placement_exposures_v1.py` 提供后续训练接入所需的三个函数：

- `expand_train` 根据实际计数提案扩展训练曝光。原始记录逐条保留一次；新数据的额外曝光使用唯一 ID，
  记录原 ID、复制序号和总次数。除 ID 与显式曝光元数据外，手牌、场况、合法动作、标签、软目标、
  来源、家族及其他元数据保持一致。拒绝验证集、已有曝光副本、重复 ID 或与实际计数不符的提案。
- `epoch_order` 保持 91,247 条旧回放的 25 来源采样结构，在每 511 条**旧回放**中保留来源覆盖。
  将新来源曝光先按池均匀展开，再均匀插入旧顺序。每个扩展索引每遍恰好一次，
  不声称每次优化器更新或每 511 条总曝光都包含全部 57 个来源。
- `choose_accumulation` 仅根据实际曝光总数，在 64–96 中优先选择接近 73 的累积量，
  使最后一次更新至少有正常更新 75% 的记录。它只提供计数建议，不确定父模型、轮数或最终训练预算。

复制曝光不增加独立样本、牌山或家族数量；同一家族的不同分数场景也可能相关。
损失占比仍由实际曝光数与单样本权重共同决定，不代表梯度占比相同。
必须分别记录原始数量、全局独立家族、各池家族、重复曝光、逐次更新来源和真实损失。
验证集保持原始唯一记录，不能用扩展训练索引计算验证结果。

四项合成测试已在现有 GPU 作业 318979 的配套 CPU 上通过：
副本追溯和原始输入/监督保持、确定性全量采样与回放覆盖、验证集/副本拒绝、变更提案和未知/缺失来源拒绝。
测试使用合成记录，不运行策略、不开启最终测试，也不证明真实数据已齐备或胜率提升。

后续仍需将该实现接入固定版本的训练入口，绑定完成的实际数据和曝光指纹、冻结合格 3B 父权重、
学习率与完整更新预算，接入保存完成后再运行验证/对局的现有回调规则。
阶段 4 的模型、完整合法动作执行策略、公开事件传递和改过的终局指令需要共同登记；
即使参数尚未更新，也不能复用旧 3B 的终局对局结果作为新策略的零步曲线。
