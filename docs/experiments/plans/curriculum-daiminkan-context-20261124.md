# 大明杠来源扩展：副露状态 × 出牌家

原189局面试点的62个非强制和牌大明杠窗口全部被Mortal选择跳过。
这些窗口只有门清手牌和上家第一次弃牌，不能据此推断所有大明杠都应跳过，
也不能反过来把“可杠”强制标为“应杠”。本次扩展只解决来源覆盖缺口。

在原32个手牌模板族上，预先固定门清／已碰役牌／已碰中张三种状态，
各覆盖上家、对家、下家弃牌，并提供两个物理世界，共576个计划。
已副露局面通过原生碰牌、弃牌和后续真实轮转构造；响应时必须有真实大明杠和其他合法候选。
每个完整物理牌山均包含136张不同物理牌，生成后的公开输入、菜单和原生前缀须逐个重放一致。

相同原手牌族的角色、副露状态与物理世界全部沿用原试点分区。
在生成前检查初始／机会牌型的花色与顺序镜像规范化；若新形状跨接了原来不同分区，
则事先隔离整个冲突来源族，不按教师结果重划分或补样。
同分区的形状别名与全训练语料的归一化、来源重叠和编码审核仍需后续处理。
若脚本前缀会放弃合法和牌，隔离并保留原因，不暗中继续或抽替代局面。

生成数据不带动作标签，脚本前缀不进入监督目标。后续独立Mortal标注仅观察公开历史和自己的手牌；
来源母题、真实牌山及其他手牌不交给教师。强制规则和牌须单独记录并排除教师网络动作标签。
报告每个分区和副露状态／出牌家组合的选择分布，不设“大明杠正例必须占多少”的筛选条件。
教师选择不等于最优价值，必要时再做公共信息条件下的动作收益模拟。

本批仍是早巡、无立直威胁、等分来源，不能代表全部防守或实战分布。
它不会进入正在运行的3A父损失控制；后续使用前须完成与全语料和保留测试族的排除审核、
确定来源配比并登记新训练。所有生成、标注和验证仅在有时限的GPU调度资源中运行，
保留日志、退出记录和私有原始数据；不更换v8或Windows模型。
