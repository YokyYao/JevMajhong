# 第十五轮登记：完整梯度与逐来源下降约束

[只读梯度诊断](../results/2026-11-19-endgame-pilot/training-head-gradients.md)证实严格追分与回放的局部梯度相反，同时随机小 batch 的来源曝光波动较大。训练守位损失下降而验证退化，说明减少训练冲突仍不保证泛化。此次不再调配比或加新标签，直接检验优化步骤能否同时保留各训练来源。

**从正式 Jev Play v2/v8 step2088 重新初始化原有决策头。** 编码器及 LoRA 全部冻结，保持实际 BF16 编码／FP32 读出，与实战同一原头、一次模型推理。全部 905／186 输入、目标、配比及终局效用沿用第十四轮，79 条零损失对照保持零损失。复用已逐条零差重放的 826 条训练表示，仅新增 186 次已用验证输入的正式 v8 编码；验证概率必须复现第十四轮 0 步，缓存原头重放同样要求 1e-7 内且首选翻转为零。验证目标不进入梯度或线搜索。

每次更新使用全部 826 条正损失训练记录，按原损失质量合成梯度。对各非零来源计算归一化梯度 u_s，令 d0 为全量梯度单位方向，求最接近 d0 且对全部非零来源满足 `u_s·d >= 0.01` 的方向。使用至多 2048 轮对偶坐标投影、容差 1e-8；退化零梯度不伪造约束。如果未收敛、方向非有限或无法找到合格有限更新，停止而不是放宽约束。

沿投影方向的负方向更新头，初始步长使头参数相对 L2 变化为当前头范数的 **0.5%**；最多 12 次减半。每次尝试只查看完整训练集各来源 CE，要求均不高于更新前加 1e-7；失败恢复原参数并停止。此精确检查弥补一阶投影不保证有限步下降的问题。新方向不是原 AdamW 路径，不能把此次变化归因于配比或某一个单因素。

最多 **8 次完整梯度更新**，相当于最多 8 次全体正损失来源曝光；每步都做完整旧验证、保存现有架构权重，连续两次无合格选模改善停止。第一步已覆盖全部正损失来源，不再用少量随机 batch 代表全体数据。旧专家 CE 起点+0.10、原回放 KL 起点+0.05、原生 trailing16/leading16 各0.05、普通第三不降、守位起点−0.02、第三23与原43/新8脱四各自原策略/起点较高值均保持，0步仅为不改变模型的锚点；不得因训练损失好看而晋级。

预检查需用现有第十四轮保存概率复算全部指标和各步原验收结论，证明新训练器没有更改验证口径。实际保存的 LoRA 必须与 v8 逐张量一致，头部确实变化；选中权重必须通过正常服务加载后的端到端控制，不能只依赖缓存头预测。非零合格候选才允许进入既定已用来源完整续打，之后仍需独立与整场确认和实际桌面接入。

这是一次有时限的小规模研究候选，配置先保持 `fit_registered=false`；代码、GPU 检查、公开 CI、缓存与数据核验通过才在私有运行配置开启。只公开方法和聚合结果，原始事件、表示缓存及研究权重不公开。正式 v8 和 Windows 安装包未变更。
