# Incremental source inventory for the continuing curriculum

The completed 3B run and a future complete Stage4 run must retain their actual
training ancestry before the independent frozen-v8 confirmation. Existing
completed source observations should be reused, rather than repeatedly scanning
the same old rollout payloads while training is waiting for new labels.

`tools/inventory_curriculum_source_delta_v1.py` accepts explicit bounded JSON
roots, an actual completed placement-base source closure and a fresh private
output directory. It follows small new metadata hash declarations, resolves
relative bundle members and reports missing, conflicting or changed declarations.
It reuses the completed base catalogue only for the same path and digest. The
single previously proved historical configuration declaration is resolved using
its original bound recovery evidence; there is no general alias exception.

New large files are listed as unread. New small files are hashed and their JSON
declarations are traversed, but remain pending typed source observations. This
inventory does not prove new raw outcome families, derive future native seeds,
admit a final candidate, open confirmation games, load a model or update weights.
It cannot replace the complete final-source producer required by the existing
confirmation contract.

A finite GPU job ran the inventory against the actual completed 3B protocol,
completion, final evidence and preserved capture terminal. Its scheduler terminal
was `COMPLETED`, exit `0:0`; all six focused checks passed.

| Observation | Actual count |
| --- | ---: |
| Assets in the reused completed base-source catalogue | 3,558 |
| Explicit 3B root files | 4 |
| Newly encountered JSON metadata files | 3 |
| Unread new large artifacts | 0 |
| Declaration issues | 0 |
| New games / model loads / optimizer updates | 0 / 0 / 0 |

The three new files are completion, final audit evidence and the preserved
capture terminal. The actual training protocol was already in the completed
base-source catalogue. This establishes the small observed delta for these
explicit roots; it does not establish global or final Stage4 source closure.
The original closed raw payloads were not rescanned.
