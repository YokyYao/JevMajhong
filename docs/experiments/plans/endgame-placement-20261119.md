# 末盘追分与守位：新增训练要求

登记日期：2026-11-19。状态：首轮 32 步早停，保留 v8；新关键窗口采集已启动，正式模型与工具尚未变更。

## 目标与行为

面向四人东风，在每局结算后记录四家实际分数、顺位及下一局场况。进入可能结束整场的末盘时，策略须根据当前顺位和分差决定是否追分：

- 第三名：优先寻找进入前二的可行路线，识别“能和但仍第三”和“足以反超”的区别。
- 第四名：同时评估脱离第四、进入前二的机会与代价，不因前二难以达到而放弃可行的脱四路线。
- 第一、第二名：保留守位对照，避免追分训练导致领先时无条件做大牌或拒绝足以结束比赛的和牌。
- 追分应影响此前的弃牌、吃碰、立直、做役及攻守选择，不只在出现和牌按钮时才处理。

“需要更高打点”取决于真实结算与整场是否结束。不得实现为末盘第三、第四名一律拒绝小牌，或只要增加副露就加分。

## 分差与结算

令当前分数为 S，候选结算变动为 Δ，目标玩家为 t，自家为 p。结算后比较 S[p]+Δ[p] 与 S[t]+Δ[t]，同分按实际房间规则判断顺位。相对分差的缩小量为 Δ[p]−Δ[t]。

例：四家分数按当前顺位为 32,000 / 25,000 / 22,000 / 21,000，自家第三，非庄，无本场与立直棒；假定此次和牌会使整场结束：

| 候选结果 | 自家 / 原第二名结算后分数 | 结果 |
| --- | --- | --- |
| 向其他玩家荣和 1,000 | 23,000 / 25,000 | 仍第三 |
| 直接荣和第二名 1,000 | 23,000 / 24,000 | 仍第三 |
| 直接荣和第二名 2,000 | 24,000 / 23,000 | 反超至第二 |

自摸须比较四家的实际付款，本场、立直棒、庄闲、多人和牌、流局罚符及同分优先顺序均应交给规则结算处理。“东四”不能直接等同于必然结束：连庄、延长和终局条件必须与实际东风规则一致。

直接荣和目标玩家只是一种可能的结果。出牌时模型不知道谁将来会放铳，不能把预想的付款对象当作已知输入。

## 当前实现缺口

已检查的主分支以 Jev Play v2 为基线：

1. `core/state.py` 与桌面 `engine.py` 已提供四家分数、场风、局数、本场和立直棒，但没有完整的局间分数轨迹或明确的末盘追分状态。`hand_number` 当前有按庄家位置推导的路径，须先核对它与原生局号、座位映射及客户端显示的一致性。
2. `training/futures.py::finish_intervention_hand` 在干预局结束后停止，不能为连庄或延长后的最终顺位提供标签。发布模型的模拟奖励为自己和牌、速度与放铳，不是整场最终位次。
3. `desktop/jev_sidecar/engine.py::recommend_reaction` 在存在 `hora` 时直接优先和牌，不经过模型比较。因此只重训权重不能使工具学会必要的拒和。
4. 现有整场评测已输出最终分数、名次与结算账本，可复用，但不能替代新增末盘专项数据与拒和闭环检查。

这些是已观察到的实现缺口，不表示已确认现有模型在所有末盘局面都会作出错误选择。

## 数据与信息边界

先实现局间账本：按对局、局号与本场记录四家结算前后分数、分数变动、立直棒池、庄家、下一局或整场终局标记。以结算事件和下一局初始分数交叉核对，处理多人和牌、流局、立直押棒与跨帧重复。桌面应保存连续场况；中途接入仍允许用当前可信分数决策，不虚构缺失历史。

策略输入只包含决策时已经公开的信息。整场未来结果只用于训练标签和离线评测，不回填当前观察；未知暗手、牌山和实际未来放铳者不得进入输入。

新增训练位置按以下维度分层：

- 当前顺位、到第二名与第三名的分差；差距不足、临界、明显不足及超额打点。
- 庄闲、局号、本场、立直棒、可能连庄或延长、同分结算。
- 门清与副露路线、立直与不立直、吃碰后打点不足或仍足够。
- 和牌与跳过同时合法的真实窗口，以及追分前的普通弃牌和鸣牌窗口。
- 领先守位与非末盘回放对照，保留原有吃碰及三种杠覆盖。

使用合法原生回放或可复现的规则引擎状态生成；不拼接无法由规则产生的分数、手牌与场况。按来源对局／牌山组划分训练、验证和独立测试，同一公开局面及其备选或共同未来不跨集合。

## 标签、奖励与续训方案

从已发布 Jev Play v2 的同一套 LoRA 和动作头续训，不为本需求额外叠加修正网络。

新增末盘标签须从同一公开局面比较实际候选，并续打到规则引擎确认整场结束。各候选使用配对的未来随机性；遇到连庄或延长继续采样，达到资源上限的截断记录不得伪装成完整终局标签。标签依赖隐藏状态与续打策略的偏差仍需记录，不能当作专家答案。

候选效用以真实终局顺位为主。首轮小试可登记一个单调的终局位次效用，例如第一／二／三／四名为 1 / 0.5 / −0.5 / −1；该数值是待验证的设计，并非麻将规则或已经有效的奖励。前二率、脱四率、净得点及放铳率分别报告，不用每次和牌固定奖励盖过终局目标。具体效用、混合比例与风险限制须在小试训练前封存。

新增数据优先补足末盘追分和守位的缺口，同时回放原有数据；不以复制少数“拒绝小牌”案例充当覆盖。先做一轮小规模分层标签与拟合诊断，再决定扩大采集和训练预算。持续观察原有出牌、吃碰、杠与非末盘决策是否退化。

## 工具与规则同步

和牌／跳过须进入可学习的合法选择路径，再同步训练、模拟与桌面服务的候选语义。拒绝荣和可能造成临时或立直后的振听，必须由规则引擎沿后续轨迹生效；不可把拒和后的状态仍当作随时能荣和。

是否拒和须比较继续比赛后的预期终局结果，而不是只比较当前牌的面值。庄家小牌连庄、足量立直棒、避免第四及继续进攻的真实成功概率，都可能使小牌和牌成为合理选择。不能先给现有 EXE 加一条强制拒和规则，再声称已经学会追分。

## 阶段目标与验证

1. 规则与输入：核对局号、座位、四家分数、本场、棒池、终局与延长条件；账本和末盘标记通过后才采标签。
2. 功能用例：覆盖上表分差、实际自摸付款、棒池补足、同分、连庄、延长、拒和振听，以及领先时应正常和牌的反例。
3. 数据与小试：核对分组隔离、真实合法动作和完整终局标签；重点观察是否能区分不足打点与足够打点，不能以“拒和次数增加”作为成功。
4. 开发对局：在固定小规模分层对照中评估末盘进入前二、脱四、守住前二、放铳和最终净得点。不见有效信号或出现明显退化即停止分析，不直接扩大轮数。
5. 独立确认：固定候选与准入条件后，才用未参与训练或选模的新牌山进行配对确认，按独立牌山组报告区间。不同初始顺位与分差分别报告。
6. 部署：确认没有被桌面“优先和牌”逻辑覆盖，真实服务请求与模拟动作语义一致，再发布新模型和工具。训练完成不等于已证明提升。

初次登记仅建立要求与方案；用户随后已授权启动，执行记录见下节。当前模型与安装包保持原版。所有计算遵守工作区集群约束：只在调度器批准的 GPU 作业内执行，不在登录节点运行计算或提交 CPU-only 作业。

### 初版小试配方（仅生成诊断标签，优化器尚未更新；当前修订见末节）

使用同一份已发布 v2 来源权重，新建优化器；基座冻结，继续 rank16 LoRA 与动作头。终局位次效用固定为 1 / 0.5 / −0.5 / −1，目标温度 0.25；每个选中位置的实际合法菜单均完成 4 次配对整场续打才可准入。当前隐藏手牌固定，只重排当前手的未见牌山，后续局沿克隆 RNG 续打；这些条件化标签不是对全部未知暗手与未来局的无偏估计。

早期 12 个完整菜单中有 5 个在有限模拟中无法区分终局效用。此类普通菜单不作为新增训练梯度，仍保留验证与诊断；包含合法和牌的中性菜单保留原有优先和牌行为，明确标识为保守先验，不把它说成模拟证明了和牌最优。其余菜单按完整终局效用构造软标签，不通过“多拒和”或“多吃碰”加分。

回放 guard 固定选 512 条原 v2 训练位置，每类门清／副露／吃碰／杠各 96 专家与 32 模拟；另用原验证集的 64 条作退化诊断。全部样本使用相同的新公开末盘输入格式，训练／验证组重新核对。损失质量按新增末盘 50%、原专家 37.5%、原模拟 12.5%分配，原模拟未标注备选继续使用掩码，单条权重上限 8；不足以满足准入时停止补数据，不复制案例凑数。

有效 batch16，LoRA/head 学习率 2e-6/1e-5，最多一轮；真实步数为准入记录数除以 16 向上取整，预计几十步，数据准入后封存。每 16 步及末步验证，连续两次无改善早停；第 0 步参与比较。选模按四类新验证位置等权的预测动作终局效用，要求旧数据目标 CE 相对起点不恶化超过 0.10。CE 仅作为诊断与 guard，不能代替终局效用或独立实力证据。若起点仍最佳，不进入大规模评测，而是检查标签信息量、数据配比与训练响应。

本轮验证集参与选模，后续完整对局必须使用新的来源／牌山作开发和独立确认；报告第三名进前二、第四名脱四及领先守位，不能用局面标签的平均收益冒充真人胜率。桌面正式接口与结算历史持久化仍需在有效候选出现后完成联调。

### 预登记的末盘开发对照

训练通过且选中非零检查点后，使用 2026112900 起 8 组新来源，每组同样按公开窗口哈希选择和牌、第三名、第四名及守位位置。每个位置从相同原生状态分别用原 v2 和候选续打到整场结束；所有候选使用自己整套后续策略。按来源组配对报告终局效用、第三名进入前二、第四名脱四、领先守住前二、点数变化及拒和次数。这里是末盘条件评测，不是整场开局的一位率。

开发信号为终局效用均值提高，第三名进前二与第四名脱四均不下降，领先守前二下降不超过 5 个百分点。该小样本门槛只用于决定是否开展新牌山独立确认，不作为已证明提升。若第 0 步仍最佳，直接跳过开发；若父作业失败，依赖评测自动取消，不留下无法满足的依赖作业。

作业 307774 登记为 307759 成功后运行，单 GPU、最长 4 小时，带退出记录。该作业尚未产生效果结论。

## 首次优化器更新前的目标与服务格式修订

本节取代上文初版小试的奖励定义；其他数据来源与新牌山开发隔离规则保持。修订发生在终局标签生成期间，优化器更新仍为 0，没有依据候选验证或开发比赛挑选奖励。

训练来源的早期覆盖检查发现：17 个和牌窗口里，落后者的当前和牌大多已经足够，实际“当前和牌不能前二、继续仍有前二机会”的窗口很少。对其中的终局名次分布作要求核对，初版 1 / 0.5 / −0.5 / −1 可能为了避免第四而接受锁定第三，不充分符合用户的争前二目标。

当前训练与开发统一使用 `top2_primary_v1`：第一／二／三／四名效用为 **1.1 / 1.0 / 0 / −0.05**，即以前二为主，第一名额外 +0.1、第四名 −0.05 作次要支持。例如锁定第三效用 0；25%第二、75%第四的继续路线效用 0.2125，能表达有前二机会时继续追分。该例是目标一致性检查，不是已证明该概率估计准确或训练有效。

现有全终局模拟保留了每动作各未来的四家最终分数与名次，因此数据准入先核对原始诊断目标，再从原始名次独立计算新效用和软标签，不重新采样、不改写来源文件。中性普通菜单不贡献新增训练梯度，中性合法和牌菜单保留基线优先和牌的保守先验。验证选模与新来源开发也使用同一前二优先效用。

服务输入登记为 `endgame-public-v2`。原生与截图均明确表示当前弃牌者、公开弃牌、荣和／自摸方式及荣和付款人；只来自当前公开状态。原始已采集请求保持原格式供回放核对，训练准入和新策略服务再作相同的规范化，未来标签或估计终局收益绝不进入输入。

### 桌面接入状态

新模型使用独立的 endgame 身份文件和单模型客户端，普通 v2 权重与默认加载路径不变。针对确认完整的末盘场况，和牌／跳过可进入一次模型推理；非末盘或未确认的场况保留原有优先和牌路径。已补齐桌面相对座位到起家顺序的映射，处理同分顺位、牌河、立直家、安全牌标记与荣和付款人的一致性。

比分历史只保存确认的公开场况，并在下一局无新立直押棒时记录可直接观察的上一局结算分数；如已经有新押棒或发生新比赛重置，不虚构上一局终局结算。另提供明确终局比分记录接口。当前桌面四家比分与局数仍沿用现有输入确认方式，尚未宣称新增了自动比分 OCR 或终局结算页识别。新权重导出、实际模型接入回归与终局结果输入联调仍待训练和效果检查完成。

新增桌面检查覆盖一次推理的和牌／跳过、旧 v2 不变、座位同分、原生／截图荣和付款人一致、比分边界去重、新押棒与比赛重置。训练专项增补了前二目标一致性用例。未构建或发布新安装包。

数据准入检查还确认，原验证集的吃碰窗口没有模拟标签。因此回放训练仍采用每类 96 专家与 32 模拟，共 512 条；回放验证改为每类 16 条专家，共 64 条，不复制或虚构缺失类别。原训练来源的完整场况记录足以满足上述配额，缺失场况的旧记录不进入本轮。

自摸也进入同一闭环：只有截图确实提供和牌按钮且手牌完成时，才生成自摸候选。确认的末盘场况允许新模型比较自摸与继续出牌，并在界面明确显示拒绝本次自摸；实际点击仍要求对应按钮存在。荣和与自摸的公开付款人特征分别规范化。8 项新策略桌面检查已在获批 GPU 作业内通过，包含真实按钮约束、自摸继续、默认 v2 优先和牌及一次模型推理。

## 公开即时结算输入修复与第四轮登记

后续专项完整终局标签拟从每动作 4 个配对未来提高至 **16 个**；具体位置清单、支持动作、置信度处理及续训配比必须在生成标签／更新权重前另行固定。既有 512 个旧回放、264 个末盘位置与原标签继续复用，不覆盖旧缓存。下一轮仍从正式 v8 初始化同一套 LoRA 和动作头，并要求关键样本真实曝光后才允许选模；本节不授权绕过先前的第三进前二、第四脱四、守位与独立确认要求。

### 覆盖结果与 512 组扩充、16 次未来标签登记

64 组配对来源正常完成；原规则目标位置 0，不立即立直来源训练 1、验证 2。扩至 256 组后，原规则训练 1、验证 0；新来源训练 17、验证 10，分别来自 17／10 个不同来源。新来源三家代理共完成 820 次合法和牌、没有宣告立直；这只是来源行为审计，不是学习模型胜率。所有来源完成支付账本检查，125 项核心检查和该提交的 GitHub 自动检查通过。训练目标覆盖仍未达 24，不放宽样本标准。

在生成任何未来标签前，将相同来源范围固定扩至 **512 组（2026116900–7411）**，仍逐四组作 3／1 隔离，复用已有 256 组，不达到阈值即中途挑停。每格选择、规则代理和目标定义不变。512 组后若仍不足则停止该数据阶段并分析，不循环加种子直到出现有利未来。

覆盖通过后，从不立即立直来源的目标位置按公开分层逐格轮询、格内哈希顺序选至多 **32 个训练／12 个验证**位置，每个原始来源最多一个；至少 **24／8 个不同来源**，否则不生成标签。清单先保存身份及哈希。复制所选私有来源到独立标签目录，原覆盖文件不改写。

对每个入选位置的**全部当前合法动作**，在相同的每动作 **16 个配对未来**上续打至原生整场结束；精确冻结正式 v8 在原路径上的策略作为自家后续决策，对手保持原有规则配置。分析与后续训练仍按第三轮以来的终局效用 `[1.1, 1, 0, -0.05]`，由实际最终位次重新计算；原始文件可保留既有生成器的旧效用诊断，不直接把旧诊断当作新训练目标。实际最终分数、位次与逐局账本完整保存。采样仅改变当前手的未知牌山，固定当前他家暗手和未来发牌 RNG，这个局限必须保留。标签不进入模型输入。

此阶段不按继续是否更好删负例、不强制学习拒和，不把单个 16 次均值当专家答案。后续先报告继续相对直接和牌的配对终局差、来源分布及不确定性，再固定训练目标和配比；`fit_registered=false` 在明确续训登记前禁止训练。配置见 `configs/training/endgame-target-labels-v1.json`。新开发与独立确认将另用未消耗来源，不能复用已看过的 4900／5900 段作为独立成绩。
