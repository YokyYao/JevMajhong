# Jev Discard Defense v1：副露听牌后的进攻与退听防守

目标是相对当前部署的Jev Play v1改善完整东风净得点。模型输入只含玩家可见信息；训练数据、逐臂轨迹和新实验权重保留本地。本计划不更改Windows安装包。

## 原因与单一调整范围

Call Risk v1已经提高放铳惩罚，但完整开发−628.13点／场。原生重放发现，部分副露听牌局面会把需要退听的现物排除。只补充这些合法现物后，96场候选四家终局分数仍逐场不变；6个关键危险弃牌均未改变。这支持直接补充普通出牌的防守学习，不能证明增加防守一定提高得点。

新控制策略采用冻结Play v1＋扩展现物准入。普通编码器与指针头为Discard v1，吃碰为Call v1，不叠加已知负向的Call Risk组件。新残差只在“已副露、自家未立直、面对已知立直、纯弃牌菜单中最低向听0、另有对全部立直者安全但需要退听的弃牌”窗口生效。合法现物与原合格选择并存，由模型决定，不强制弃和。

## 数据与标签

- 96个未用过的整牌山，按原注册方案轮转三种对手组，每牌山四个被测座位，共384场完整控制东风。每牌山只对应一种对手组，不能当作96×3×4场。
- 每四个连续注册牌山中前三个训练、第四个内部验证，共72／24牌山。同牌山的全部座位、状态、动作及未来留在同一分组。
- 收集所有符合公开条件的窗口，不根据后续和牌、放铳或分数挑例。先保存实际控制轨迹、决策位置、公开请求和冻结模型输入，不为原始状态虚构分支支付。
- CPU核对完整四家账本、原生动作前缀、合法动作与准入、缓存概率。缺失或损坏的分片先检查，不静默替换。
- 每状态16组预先确定的共同未来，固定当前四家手牌和已揭示信息，重排未见牌山。比较控制动作和替代弃牌，并补全每个状态全部合格选择；同一状态复用控制与已生成分支。
- 标签是当前局结算的实际净得点／8000＋0.1快和支持−0.4放铳。没有吃碰、退听或打现物次数奖励。16未来不能穷尽对手暗手与后续策略不确定性。

## 拟合与阶段目标

| 阶段 | 检查与进入下一步的条件 |
| --- | --- |
| 接口前缀 | 正式96牌山中的前4个先完成；16场、24状态及24原生重放已通过，后续直接复用 |
| 完整采集 | 全96牌山384控制完成、整牌山划分及原生输入审计成功 |
| 收益标签 | 父标签及全部合格动作对照完整、实际支付均值和来源审计成功 |
| 拟合 | 158维公开特征、16隐藏单元、2560参数；原底座／LoRA／指针头冻结，零残差初始化，先验强度0.05 |
| 训练与选模 | 每公开状态等权，不按收益方向重加权；最多32轮，连续4轮验证遗憾／KL均不改善即停，零起点参与 |
| 开发 | 先核对全部检查点、零起点和真实推理；内部采样选牌收益有改善才做8牌山192场，复用96参考，只新增96候选 |
| 独立确认 | 开发净得点正向才固定同一权重与规则，使用仍未消费的32新牌山768场；整牌山配对净得点区间下界>0才确认提升 |

内部指标是按状态等权的采样收益遗憾，不能代替完整东风得点。内部验证及开发已经用于选方案，最终确认不能再参与拟合。独立确认失败不在相同测试牌山上反复调参并宣称独立提升。

实际推理预检覆盖防守窗口、其他普通弃牌、吃碰、含杠菜单各2例。候选使用扩展防守准入，参考仍为原Play v1；记录新增与实际选中现物次数。净得点比较包含整个候选系统的变化，不把差异全部归因于残差训练。

## 失败后如何继续

没有内部提升就先检查标签方差、各动作覆盖和特征能否区分风险，不追加同数据训练轮数。内部提升但开发负向时，检查改选前缀、实际放铳支付与连续决策差异，定位问题后修改数据或策略范围。开发正向但独立区间跨零时，保留未经证实的结论；不能把鸣牌或弃和次数增加当成目标完成。

Call Coverage v1保留已有注册数据实验，独立记录结果。两条实验不混用权重或改写已完成标签。公开配置位于`configs/training/defense-*.json`；作业用不可变源码副本运行，后续目录整理不会改变已有采集。
