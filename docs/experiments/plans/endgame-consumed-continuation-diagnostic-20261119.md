# 已消耗开发局面的自续打诊断

第十一轮仅训练动作头仍未达到要求，且在完整曝光前因守位下降停止。第十／十一轮的离线指标都来自“当前动作后按原v8继续”的有限终局标签；真正使用更新后的策略时，后续行为会改变。下一步先用固定的小组已消耗开发局面检查这层关系，不直接增加训练轮次或数据，也不改变模型发布条件。

固定两个未通过的研究检查点：第十轮72步、第十一轮48步。原始拟合结果继续保留0步选择；诊断运行器必须显式使用研究检查点，不能修改拟合结果、伪造晋级资格或把未通过模型当成更强教师。

只在已经消耗的标准7900段与专项9900段开发池中选择12个窗口：专项池当前第三／第四各4个，标准池当前第一／第二各2个。按当前公开顺位及固定哈希选择，每原始种子最多一个；不看候选结果、旧对照输赢或未来标签收益。保留既有来源牌谱与窗口，配额不足就报告，不用新独立来源补齐。

复用第六轮已存原v8对照，只读核对权重身份、原始窗口、公示得分顺位、协议及终局账本。开始候选诊断前，按固定公开规则选择一个非和牌守位窗口，重新按原v8从原生前缀完整打到终局，必须逐字段复现已存对照；否则停止并调查。先冻结12窗口清单，再运行两个研究检查点，每个12次完整续打；对照核对之外不重复原v8比赛。继续使用原规则、对手与完整终局上限。

报告两组各自的第三进前二、第四脱四、领先守前二、终局效用与净得点差，并保留来源组配对。12个窗口仅用于定位离线标签／实际后续策略之间的差异，不能声称已证明胜率提高，不设置模型晋级或部署判定；独立确认与完整开局来源保持未使用，也不能把这些开发结果回填训练。

所有计算在有时限、日志和退出状态的调度器GPU作业内进行，冻结来源、代码、库与权重。对外只公开配置、代码和聚合诊断，原始牌谱、清单、逐场结果与检查点保持私有。完成后结合训练拟合与参数归因结果，再登记下一轮训练修改；本阶段拟合、晋级和导出均关闭。
