# Jev Unified Attack v7：补充进攻局面并修正候选范围

v6完整768场独立确认未证明提升：相对现有组合，和牌率-1.6890个百分点，净点-1847.66/场，二者95%区间均跨零。本轮优先修正已查实的数据问题，再训练同一个统一LoRA和动作头。

## 假设与边界

模拟普通弃牌554条中521条有对手立直，副露后弃牌243条全部有对手立直。无人立直时的普通进攻覆盖不足。另有243条副露后弃牌模拟标签包含实际候选规则排除的动作，70条首选被排除，平均排除概率30.19%。这些诊断不是效果变化的因果证明。

维持桌面与评估现有向听/安全候选规则；只对旧副露模拟训练标签在实际候选范围内重新归一化。此操作是已有监督的条件化，不是新增模拟、专家答案或收益估计。专家标签保持不变，其余模拟目标保持不变。旧模拟后续使用扩大防守候选的局限仍需披露。

新增数据来自无人立直、本人未立直、分数/本场/立直棒/牌河/副露/手数信息完整的普通出牌局面，分别覆盖门清与副露。原生对局控制和未来延续使用现有正式组合及标准候选规则。未来延续并非新统一模型的在线自博弈，隐藏手牌固定和有限未来带来的偏差仍存在。

第一次采集作业300202在生成对局前因流程白名单遗漏失败，零完整数据分片，未训练模型。修复明确准入三种进攻采集/重估类型，保留模型校验和冻结动作头约束；新增回归检查后本地241项核心检查通过。

新源码和配置重新封存，使用全新12组牌山、48场完整控制对局。GPU采集作业300211已在RTX 5000 Ada运行；CPU独立回放审核300212仅在其成功后执行。审核逐步枚举全部合格机会，对齐原生状态、动作候选和结算，要求门清、副露均有覆盖，且没有对手立直。该阶段没有优化器更新，不代表v7已经训练。

## 后续阶段与拟定预算

1. 输入审核通过后，先做24个原始局面的成本试跑：门清训练8/留出4，副露训练8/留出4；每个局面16个共同未来，并补齐实际候选范围中的全部备选动作。未来和结算另做数据审核。按局面/牌山隔离训练与留出，不按收益或标签筛选。
2. 依据实测成本确定完整采集预算。拟采96组全新牌山，按整组72/24划分训练/留出；目标新增训练门清384、副露256条，分别以每组最多6/4条覆盖至少64组训练牌山。拟新增留出48/32条。覆盖不足时补充新牌山，不复制样本凑数。完整预算须在观察收益和开始训练前固定。
3. 修正旧训练标签，追加新数据并完成全量校验后，封存最终配方。拟从未晋级的v6末步2048继续同一LoRA/head，新建优化器；奖励保持自己和牌+0.25×折扣速度-放铳，净点权重0。拟保留原32768条唯一训练位置并追加640条，共33408条，微批1/累积16，完整一轮2088步；LoRA/head学习率2e-6/1e-5，rank16。原540条验证保留，拟追加80条新留出；以最终准入数据为准，训练前冻结，不在训练中改配方。
4. 每256步验证，验证CE仅作诊断；预登记末步作为唯一对局候选。原生推理与全部数据准入通过后，执行新192场/8组牌山开发对照；和牌率均值增加、放铳率增加不超过1个百分点才进入新768场/32组独立确认。确认要求和牌率变化95%区间下界大于0且满足原风险条件。未通过就结束该轮，分析并修订下一轮，不加补救比赛或改选检查点。
