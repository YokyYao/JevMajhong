# Jev Unified WinRisk v5：降低模拟标签的不稳定性

v4完整训练32768条记录后，192场初筛和牌率下降0.74个百分点、放铳率上升3.08个百分点、净点下降1717.71/场，未通过门槛。完整覆盖与更低验证CE没有证明实战提升，因此下一轮调整监督标签，不再仅增加训练轮数。

## 训练数据诊断

仅从实际准入的3143个模拟训练局面重建收益，未读取验证分组的模拟明细或当前评测比赛明细。2759个局面各16个共同未来，384个各32个。将未来按奇偶拆成两半，首选动作一致率63.16%；允许并列最优后的集合相交率74.04%。杠窗口的两项指标为51.64%和65.57%。193个局面的原始动作概率超过90%，但该首选在配对bootstrap中的含并列支持率不足75%。支持率只是条件于已有模拟的敏感性诊断，不是专家正确率。

这些结果支持检验标签不稳定这一因素，不证明它就是v4退步原因。源码另确认原始动作分支采用固定组合模型继续打完当前手牌，统一模型会改变后续动作；本轮暂不同时调整这个因素，仍明确保留其局限。

## 单项改动

对每个模拟训练局面的完整共同未来集合做256次有放回重采样。每次按相同索引同时抽取所有动作及其收益字段，保留动作间配对关系；重新计算现有奖励和兼容规则下的动作概率，再取256个概率分布的平均作为训练目标。种子固定为规范化训练位置SHA256的前16位。256次重采样不是新局面或新证据，不增加训练记录数。

不删除不确定局面、不筛掉负收益、不改变奖励或来源/阶段损失系数。原先未知的合法动作继续保持未标注掩码。平均后的标签不保证每个局面都更平，也不保证游戏效果更好，必须重新对局验证。

独立实现已在全部3143个准入训练局面上重算，与审查生成的标签文件逐项一致。维护代码通过228项本地核心检查，包括共同未来保持并列动作、重采样的动作排列不变性、确定性及不确定标签的行为检查。

## 固定训练与阶段目标

1. 训练集仍为32768条唯一记录、验证集540条原始字节不变；只改模拟训练目标与对应首选标签。CPU作业299789负责检查全部公开模型输入不变，并实际比较160个分层样本的编码。数据、来源权重、祖先训练/验证隔离和源码哈希通过后才准入GPU。
2. 与v4相同的v1末步512实验初始化，新优化器，冻结Qwen3.5-0.8B基座，单一rank16 LoRA与动作头。BF16、微批1、累积16、种子2026111407，LoRA/head学习率2e-6/1e-5、完整一轮2048步，保持学习率调度预算不变。每256步保存并验证，唯一对局候选预登记为最终2048步，不按CE挑旧检查点。
3. 奖励仍为自己和牌+0.25×折扣和牌速度−2×放铳，净点系数0。专家/模拟损失质量75%/25%，模拟内部门清40%、吃碰30%、杠20%、副露后出牌10%。无额外修正网络。
4. 完成训练后核验所有检查点和540条验证预测、最终优化器游标及完整数据覆盖，再通过540条原生推理检查。使用全新192场开发对照（8组独立牌山）及独立台账审核；和牌率平均增幅>0、放铳平均增幅≤1个百分点才进入全新768场确认（32组独立牌山）。
5. 确认门槛仍为和牌率95%区间下界>0且放铳平均增幅≤1个百分点。未通过就停止该轮，不增加补救比赛，不换旧检查点，不部署；根据完整证据再修改下一轮。对局统计不能证明真人实战效果。

本轮只公开代码、配方、方案与聚合；训练局面、重采样明细、分组清单及实验权重保持私有。现有正式模型和Windows安装包继续保留，等待真实提升证据。
