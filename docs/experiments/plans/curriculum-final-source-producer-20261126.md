# Final qualified-model source evidence

`tools/prove_curriculum_final_source_catalog_v1.py` implements the missing join
between completed source observations and the final-confirmation consumer.
It does not choose a checkpoint, train a model, run matches, create a final
registration, or publish raw records.

Before writing a final source receipt it requires:

1. The actual complete Stage4 final budget and original passing development
   assessment, plus the independent execution audit. An earlier checkpoint or
   the intermediate 3B grade cannot substitute for these conditions.
2. The exact candidate bundle and frozen v8 bundle, the same pinned pretrained
   base, and the actual complete TRAIN ancestry and validation inputs of both.
3. The completed base-source catalogue, all original 108 targeted views
   accounted for as complete labels or explicit quarantines, their stored
   value/native-seed observations, and the complete placement row-origin proof.
4. The actual new 3B metadata observations. Prior raw source evidence is reused;
   new case/cache hash declarations are traversed, and new bounded metadata is
   observed. Unfamiliar data/binary inputs, conflicting hashes, missing files,
   unreviewed reserved occurrences and missing lineage coverage are rejected.

The producer preserves the original source hashes in its completion binding.
The existing sealer and final consumer must recheck those actual files before
reserved outcomes can be generated. Data from the reserved final comparison
must remain unopened while this evidence is prepared.

GPU step `326753.3` passed eight boundary tests and checked the existing 3,558
base role entries against their completed identity catalogue. It also attempted
the real final-proof entry with the currently absent Stage4 registration and
confirmed rejection before any output. No raw payload was rescanned, no model
was loaded, and no game or optimizer update was performed in this preflight.

**This is software preflight evidence. The full final source proof has not run,
and no final comparison has been admitted.** The actual future join remains
subject to its real completed inputs and complete source-graph coverage.

The finite GPU entry is `cluster/curriculum-final-source-proof-v1.slurm`, with a
one-hour scheduler limit, a shorter process timeout, an exit receipt and no
automatic requeue. It is to run after the genuine complete source producers
and qualified Stage4 audit. A failed or partial output must be preserved rather
than overwritten; incomplete inputs cannot be relabeled as a successful proof.

This source proof is separate from training admission. It does not add a
sampling quota, strategy veto, or evaluation workload to an active fit.
