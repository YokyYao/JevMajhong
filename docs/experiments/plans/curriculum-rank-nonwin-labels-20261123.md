# Stage4: rank-aware action values before a legal win

This extends candidate-data production beyond win/PASS decisions. It does not
admit a student fit, deployment policy or strength claim.

Select8 TRAIN and2 validation source families per category:progression draw,
post-call discard and call response. Families are distinct across categories
within each split. Every selected physical decision receives four existing
public score views:hold second, third gap3000, fourth gap5000 and fourth gap13000.
The fixed cohort has96/24 views from24/6 families. These are120 score views, not
120 independent source games. Family selection uses a fixed public-ID hash
ordering and category/context availability, never rollout advantage or wins.
Reserve scarce public kan/riichi/call operation opportunities when available,
before filling the same fixed quota by hash order. Record availability gaps;
an offered operation is never automatically labelled as the selected action.

For each view use the actual frozen practical-v8 current choice as the first
candidate, captured with one inference. Add publicly available operation types
and discard shanten/safety/probability alternatives, up to4 distinct actions.
This proposal budget is not a deployment filter or a teacher label. Call
responses include the offered chi/pon/daiminkan/PASS representatives when all
four exist. Ordinary choices can contrast riichi/kan with discards. Untested
legal actions have zero target entries meaning UNLABELLED, not negative labels.

Sample two independent blocks of16 public-history worlds. On every same world,
execute every selected candidate and complete the remaining native match with
matched later-hand seeds. Continue with the frozen v8 and public heuristic
opponents. At later legal wins the observer uses the existing same-objective
rank-first replanner, four inner worlds, depth one and at most four plans per
outer arm. Never install original Mortal private histories into sampled hands.
Mortal supplied source play, not a counterfactual stateful Bot.

Choose by expected top-two frequency, then lower terminal rank, with bounded
net as a tie-break only when initially third/fourth. Exact placement ties retain
the current reference. Use512 paired bootstrap replicates with positive
smoothed mass on all tested actions. Keep uncertainty and report independent
block/leave-one agreement; no positive-only filter, confidence gate or fourth-
escape veto. SamplingExhausted quarantines a whole view, never partial worlds.
The prior, opponent behavior and bounded continuation remain approximations.

The maximum outer budget is15360 completed arms, with inner arms counted
separately. Three sequential GPU array tasks handle40 views each with a12-hour
limit/task; preparation and merge have their own finite GPU jobs. Existing
training and win-label collection are not cancelled. This course can queue
after the earlier array to respect the two-running-job QOS limit.

Store each completed view and actual terminal events privately. Merge checks
every ledger and reconstructs every soft target. Categorize outputs by original
family/split/category/context; publish source/config/plan and aggregates only.
An all-late placement-input/instruction contract is still required before
fitting non-win targets; the earlier win-only input bridge must not silently
train these examples with a conflicting hand-win-first objective. Data mix,
parent, optimizer, full student fit and closed-loop/final-v8 evaluation remain
pending. Current models, Windows, main and the untouched final grid stay fixed.
All compute/testing/hashing uses bounded scheduler GPU resources; no login
compute, CPU-only workaround, detached worker or background polling.
