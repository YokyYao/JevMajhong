# 第九轮诊断后的领先普通决策保留准备

第九轮从正式v8续训56步，完整841条训练记录已曝光，选回0步。第四名验证脱四估计从0.412064升至0.415698，仍低于原策略0.436047；第三名追前二效用从0.447962升至0.469701。后者是带第一／第四小幅区分的前二效用，不是前二率。

提前停止也由守位退化触发：守位验证效用在48／56步从0.969792降至0.928125，超过原有0.02容忍度，连续两次触发停止。该过程核对了真实保存的训练状态、唯一曝光和耐心计数；不是观察超时、没有跑验证或漏见数据。原专家CE及新普通上下文KL仍在各自范围内，表明均值保留指标不能充分保护少量关键守位动作。训练集117个第四名位置的脱四下限违规由18降至7，目标CE由1.076518降至0.993194；训练有所拟合，尚未达到泛化与守位要求。不能仅凭这些训练变化延长原作业。

下一步先复用现有80个原始种子组、各自标准／不立即立直两份完整牌谱，补充**末盘当前第一／第二名的普通决策输入**。固定64训练／16验证，第一和第二各32／32、8／8，跨两个来源代理每种子最多一个；沿用原3／1来源划分。它们和已有落后输入可以同源，但绝不能跨训练／验证；独立来源组数量不因此翻倍。排除合法和牌窗口，只保留原策略实际支持至少两个选项、会调用网络的弃牌／立直／吃碰／杠菜单。

按当前公开顺位、动作阶段、门清／副露／立直及东四／延长阶段分层，格内哈希与配额可行性抽样，不根据后续输赢筛选。160份牌谱逐事件重放，核对已登记和牌前缀与最终得分；这些核对只验证来源完整性，不用于选择。范围外的学生输入必须逐字段等于原v8输入，不能为领先者加入追分字段。已有落后抽取配置与规则保持原默认行为。

本阶段只准备无标签的公开输入配对：`configs/training/endgame-leading-context-v1.json`。不查询教师、不更新优化器、不追加模拟未来，不将其伪称专家答案；教师与拟合注册保持关闭。若80来源不能满足配额，报告不足并保留原清单，不按输赢补抽或降低条件。原始牌谱和逐位置文件保持私有。

数据准备完成后，先核对本轮训练源间的保留／追分冲突，再登记下一轮实际配比和训练预算；不在这份输入准备方案里偷偷启用第十轮。最终仍需同一模型完整续打、未消耗的独立确认及实际导出权重桌面推理。桌面已补本轮输入版本的范围判断与原格式回退，测试使用模拟接口仅验证格式和一次调用，不是训练模型部署证据。
