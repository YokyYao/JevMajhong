# Fixed targeted labels: complete-world recovery

The original 108 selected views, two independent blocks of 16 worlds,
complete current legal menus, frozen continuation policy, bounded future-win
planner, soft targets and quarantine rules remain unchanged.

The original running array is not modified or restarted. A later recovery may
start only after every prior writer has a genuine terminal record and exit
receipt. Previous artifacts are preserved in exclusive attempt directories.

Each recovered partial case checkpoints one **complete world**, including all
current candidate arms, their full-match ledgers, future-plan records and exact
observer diagnostic state. Atomic exclusive publication prevents partial worlds
from becoming cache hits. A cache hit requires the same frozen collection,
source, allocation, reconstructed world receipt, ordered menu, baseline, seed,
anchor and preceding diagnostic state. Conflicting results are rejected.

The original world construction still runs before lookup. On a miss the entire
original per-world calculation executes unchanged; an AST roundtrip checks that
only cache lookup/publication surrounds it. On a hit all arms and diagnostic
state are restored. Labels still require both full 16-world blocks. Incomplete
worlds never provide targets. Completed cases retain the earlier recovery path.

Validation first checks seven cache/AST contracts and then roundtrips the fixed
first three completed training cases through the cache, reconstructing physical
receipts, native settlement ledgers, counters and original full32-world labels.
The historical counter reconstruction proof is restricted to cases with zero
outside-scope/unsupported-kan offers; runtime cache validation handles all seven
counter types directly. This is saved-data/software evidence, not a fresh model
rollout or a claim that teacher targets are optimal. No policy is loaded.

All checks and recovery work require scheduled GPU allocations. The worker has
a 12-hour scheduler limit, a 710-minute subprocess limit and an exit receipt.
No persistent observer or login computation is introduced. Full four-shard
merge, model-input projection and later training admission remain mandatory;
this cache alone does not admit data into stage 4. Raw packets remain private.
