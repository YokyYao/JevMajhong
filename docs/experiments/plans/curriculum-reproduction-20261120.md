# Jev Curriculum v1：从 base 重训的四阶段路线与曲线记录

状态：方案、公开数据恢复和首轮覆盖核查完成；日志/绘图实现进入检查，尚未启动优化器。2026-11-20，Asia/Dubai。

本轮整理用户提出的四阶段课程，从固定 Qwen3.5-0.8B 新建 rank16 LoRA 和256维动作头，冻结预训练主体。v8/Jev Play v2 保留为冻结参照。阶段间续训同一套参数，保留基础能力回放；不增加外部决策修正网络，不加载 Mortal 蒸馏模型。

这是依据 v8 经验重新组织的课程实验。它不是原 v8 全历史分支的逐字节重演，也不预设能达到 v8 的棋力。阶段效果与训练日志不足时，不能补画结果或写成已经学会。

## 历史事实与新路线

实际 v8 参数主链为：Qwen base → Balanced Base v2的1536步 → WinRisk v1末步512 → WinRisk v5末步2048 → v6末步2048 → Attack v7末步2088 → AttackRisk v8末步2088。Warm v2以及WinRisk v2/v3/v4是旁支，不应全部串入参数谱系。历史选模文件的最低CE步与预登记对局候选末步需要分别记录。

v8 已同时学习门清出牌、副露后出牌、立直、吃碰、三类杠和跳过，其模拟监督兼顾和牌、速度和放铳；没有完成后来新增的终局前二课程。不能将四阶段的新叙述倒写成原模型实际经历。

| 新阶段 | 目标与数据 | 需要验证的能力 |
|---|---|---|
| 1 基础牌效 | 公开牌谱的普通出牌与立直决策，合法候选、向听与有效牌；审核役牌、客风、门清/七对等不同结构覆盖 | 普通出牌质量、立直/不立直；明确区分模型策略与规则引擎直接提供的合法和牌能力 |
| 2 鸣牌和后续推进 | 吃/碰/暗杠/大明杠/加杠的实选与放弃，以及副露后出牌；同时回放阶段1数据 | 各操作有机会时的实选/拒绝、无役风险、鸣牌后的出牌；不奖励单纯增加鸣牌次数 |
| 3 进攻与风险权衡 | 回放专家数据，加入 v8 公开的共同未来软标签，学习和牌概率、速度与放铳代价 | 完整东风和牌率、放铳率、净点；不能只凭模仿一致率或CE判断棋力 |
| 4 终局位次 | 根据完整公开分数/座位/本场/立直棒及剩余局数，生成追分和保分局面与终局收益标签 | 末局第三/第四追前二、领先保位，按起始名次与分差报告；不对所有状态一律偏好小牌快和 |

场风可形成役牌，不设“固定先弃场风”的训练规则。孤张客风也应结合牌形、巡目与安全性评估。阶段1的和牌/牌型教学必须有数据与专项结果支持：若现有数据没有和牌选择标签，只能报告规则准入与出牌模仿，不能称其已学会和牌价值或番符计算。

阶段4首先区分目的：领先者的小牌快和可能锁定名次；落后者需要足够打点或直击对手。1000点在某些场景会结束比赛且仍未追上，不应普遍给予快和奖励。第四名追前二允许风险，不采用“脱四概率绝不能下降”的硬否决。

## 从第一步记录曲线

所有事件追加写入JSONL，并导出CSV。绘图读取真实事件；保留原始点，平滑图须同时展示原始点及平滑窗口。阶段切换标线、局部step与累计step同时显示，优化器重置必须标明。不同损失或奖励定义不拼接为同一个可比数值。

| 文件 | 记录粒度与字段 | 对应曲线 |
|---|---|---|
| train_metrics.jsonl | 每个真实optimizer更新：run/stage/local_step/global_step、样本数/去重曝光、实际总loss、专家CE/模拟masked CE、各阶段损失、各学习率、梯度范数、用时 | 原始/滑动平均训练loss；各来源loss |
| validation_metrics.jsonl | 每128步及每阶段起终点：固定验证集SHA、分层CE、一致率、各操作机会数/教师实选数/命中/误选 | 固定口径验证loss、能力分项；不能将一致率当胜率 |
| evaluation_metrics.jsonl | 每256步及阶段起终点：完整东风场数、独立seed组数、对手/座位、检查点哈希、每场reward分项、和牌率/一位率/前二率/四位率/净点及区间 | reward曲线、和牌率曲线、名次曲线、净点与放铳率 |
| matches_private.jsonl | 每次完整对局的事件、四家终局分数、和牌/放铳及速度、reward分解，绑定checkpoint与评测网格 | 重算聚合与误差条；原始记录不自动公开 |

阶段1/2是监督学习：训练reward记为null，不画伪造的“训练回报”。如阶段起终点及周期评测使用同一个固定的对局效用，其实测evaluation reward仍可绘图。阶段3软目标loss也不是在线RL reward；对局实际回报与缓存标签估值分开记录。阶段4奖励定义改变时分面展示，并另外用相同的固定评测指标比较四阶段。

共同评测效用先固定为终局原始净点/8000，另列终局前二指标及阶段3的和牌/速度/放铳分项。效用是曲线指标，不等于每阶段梯度优化的目标。所有频率带分母；“胜率”分别命名为小局和牌率、整场一位率和前二率，不合成单条含糊曲线。

周期对局采用固定16场开发小网格（2组种子×4座位×2对手组合），用于走势，至少保留至训练结束再解释，不能当作精确实力估计。每阶段末用固定64场开发网格作对照，与v8使用相同规则、格式和候选。小网格是64场网格子集；重复checkpoint/同网格直接复用已完成结果，不重复运行或虚增样本。每条曲线显示独立seed组数；小网格区间可能很宽。

最终比较另用未被曲线/调参消费的新seed组，预先固定32组、4座位、2对手组合=每策略256场。原v8冻结参照、新课程最终候选均在同网格评测，以整seed组配对统计。该最终测试不参与选模；不把开发曲线的最高点直接宣称最佳泛化成绩。不为画漂亮曲线追加补救对局。
