# 保留已有基础能力，继续训练统一麻将 LoRA

**Jev Unified Warm LoRA v1 已启动实际训练**。它从 Jev Balanced Base LoRA v2 第1536步的完整LoRA与动作头继续训练，同一套参数处理普通出牌、立直、吃碰、三种杠及跳过。冻结的base仍为 Qwen/Qwen3.5-0.8B，版本2fc06364715b967f1860aea9cf38778875588b17；不叠加外部决策网络，不组合多个模型推理。父模型只是训练起点，优化器重新初始化。

## 为什么修改

三个从通用base新建LoRA的候选均未达到完整对局提升要求。v3在640步早停，选中256步，该权重只经历4096条源记录更新。完整192场、8组牌山的独立审计显示，相对保留策略自身和牌率−10.05595个百分点（95%区间−17.08630至−3.02561），净得点−4787.5点/场（−9023.80至−551.20），放铳率增幅均值1.04204个百分点，未通过原1个百分点限制。未启动其768场确认，不替换正式模型。

普通出牌学习不足、稀有动作条件未学好，以及吃碰样本先验变化，都是待检验的原因。v2训练了更多基础记录，普通出牌验证CE也更低，因此选择其统一LoRA作为本轮初始化；不同模型使用了不同牌山，不能据此断言v2棋力更强。降低学习率并保留父模型吃碰采样分布，目的是保留已有能力后学习真实杠案例，不是给所有吃碰杠加奖励。本轮同时改变初始化、学习率及吃碰采样，不能作为单因素因果实验。
