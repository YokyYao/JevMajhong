# 普通第四名训练目标的逐世界稳定性审计

第十五轮每类训练CE下降，但已用验证整体软终局效用下降；只增加同一训练权重的步数缺少证据。下一步先核对训练目标可靠性，暂不登记第十六轮候选训练。

固定全部 **55个普通第四名训练位置**，包括原23个四世界位置及新增32个十六世界位置，保留其中19个明确改进来源和36个保持／并列来源。不访问验证位置、不挑成功案例、不产生新的未来或模型查询。读取已保存的逐动作、逐世界完整终局结果，逐文件核对训练元数据中原始SHA256、原正式v8继续策略身份、合法菜单次序、座位、比分账本与终局名次。

由同一终局名次重新计算既定效用1.1／1／0／−0.05和脱四标记，要求完整世界均值与当前训练元数据一致，严格来源19个的定义及当前目标原样复现。审计不覆盖或修改任何历史标签、文件或配比。

每次留出一个世界，对剩余共同世界重新计算全部动作的均值、以原贪心动作脱四值为下限的支持范围和既定`greedy_improvement`目标。按原有菜单次序选目标首选，再在该留出世界上比较其与原v8贪心动作的效用及脱四；各动作始终使用相同留出索引，不能独立重采样破坏配对。报告完整目标支持／首选的稳定比例、严格改进是否仍成立，以及留出世界平均效用差和脱四差，按原23／新32及严格／保持来源分别汇总。

这些世界固定了当前隐藏暗手且来自同一继续策略，并非独立新牌局；留一法不能证明真实胜率或提供无偏总体效应，最大动作选择也可能有选择偏差。结果只用于决定下一步应提高标签世界数、扩展训练覆盖，还是调整可训练表示。无论发现何种问题，都须先登记新数据与候选配方；旧验证和独立来源继续隔离。

实现、GPU检查和公开CI完成后才执行；配置见`configs/training/endgame-training-label-stability-v1.json`。当前仅登记，不声称审计已经完成。所有数据处理在限时GPU调度资源内进行，只公开方法和聚合结果。
