# Finite terminal-dependent continuation into retained3B

The current3A fit already has independent audit and terminal-preservation
jobs. Bind a separate finite GPU bridge before parent completion and submit
it held with an actual afterany dependency on that terminal job. Verify its
real ID, source command, dependency, GPU1/CPU1/4GiB/five-minute request before
release. It performs one execution, not polling or background computation.

Preserve the terminal-capture job's actual completed scheduler record and
matching exit receipt before scheduler expiry. Existing genuine archives may
be revalidated; missing records are never reconstructed. Then recheck the
unchanged original final2400 parent grade, full independent audit, source
binding and captured fit/audit success. A failed grade, missing phase or
changed source rejects admission and leaves an explicit failed bridge receipt.
Do not override gates, restart a parent or select an intermediate high point.

Only after actual qualification, invoke the already source-bound retained3B
launcher. It submits held preparation/fit/audit/capture jobs, binds their real
IDs and releases the chain. No child job is submitted merely by queuing this
bridge. A matching existing child queue is preserved without restarting it;
inconsistent or partial child artifacts require investigation. Submission
errors clean up only jobs created by that submission.

Within this isolated scheduler process, adapt only the first preparation
sbatch command to require successful bridge completion and cancel if that
dependency becomes invalid. The original launcher, formulas and remaining
fit/audit/capture dependencies are unchanged. Restore the local process API
after submission and verify the actual held preparation dependency. Thus
new compute jobs cannot run before the bridge finishes, and a bridge failure
or timeout invalidates the preparation and its dependent compute chain.

Six tests cover original-grade and phase rejection, actual capture evidence,
duplicate avoidance, exact held dependency/resources and preparation cleanup
dependencies. The bridge's source,
test evidence and existing parent/child bindings are frozen in an allocated
GPU preflight. It cannot load a model, run games, update parameters, admit a
fourth-course fit or open the final comparison. The main3A recipe, original
qualification and all raw privacy restrictions remain unchanged. Data-job
parallelism and optional accelerator changes are separate from this bridge.
