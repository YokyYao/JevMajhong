# 第四阶段训练与验证指标

`tools/curriculum_placement_metrics_v1.py` 为后续训练入口提供实际逐次更新损失汇总和唯一验证集诊断。
它尚未接入学生训练；标注、合格父模型和固定训练登记仍需完成。

## 必须分开看的指标

| 指标 | 说明 |
|---|---|
| 逐次更新 loss/CE/额外立直类损失 | 对本次实际曝光逐条按登记权重求均值，允许稀少来源缺席某次更新 |
| 各来源验证损失 | 原始唯一验证记录；保留 25 类旧回放诊断，增加 32 类终局数据诊断 |
| 未标注动作选择率 | 按完整合法菜单、实际立直/和牌选择规则选出的动作，在目标中是否为零支持 |
| 选中动作对应的软目标数值与标签一致率 | 只说明与近似教师偏好的关系，不是和牌率、前二率或对局价值 |
| 完整东风 reward、和牌率、前二率、净点、放铳率 | 必须由实际完成、账本核验的对局产生，独立于监督损失 |

旧回放保持原损失公式，但其中终局指令已经按已声明的 placement 投影改变。
旧标签在新目标下的分歧需要保留诊断，不能把它们一概称为最优终局答案。
验证中，普通立直窗口按完整立直类概率 0.5 的既定执行规则选择；
当前和牌窗口则按完整当前菜单选择并在平分时接受和牌。两者的决策规则不同。

部分来源只标注两个或少数动作，对其他合法动作不施加伪造的负标签。
因此 masked CE 可能保持很低，同时完整执行选择了未标注动作。
新增诊断明确记录这一比例，不能把未标注动作的目标零值当作真实收益零。
从缓存概率重建诊断损失使用明确的 1e-30 对数下限；真实优化器 loss 仍来自前向计算的日志。

四项合成测试已在 GPU 作业 318979 内通过：
保持 masked CE 不变、却把完整菜单选择转到未标注动作的反例；
实际立直类与和牌菜单不同的选择规则；稀疏来源逐条权重汇总；
缺失/重复/训练/曝光副本/顺序不一致验证记录的拒绝。
它们不证明全量实际 57 来源验证已经运行，后者仍需等真实标签完成并接入固定训练入口。

该新增代码不影响当前 3A、排队的 3B 或配比核算作业。
新指令与当前和牌选择策略改变了终局行为，第四阶段零步完整对局也需实际重跑，
不能直接复用 3B 对局缓存冒充新策略曲线；最终未用于调参的 v8 对照仍保持未开启。
