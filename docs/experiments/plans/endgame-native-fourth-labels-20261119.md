# 复用普通第四名局面，补全终局动作标签

本阶段只生成标签，不更新模型或发布候选。依据是[完整续打诊断](../results/2026-11-19-endgame-pilot/consumed-self-continuation.md)：一次脱四退化的首次分歧是普通弃牌，而现有新增监督较多集中在和牌窗口。数据可复用，缺的是部分普通局面的终局监督。

复用既有 trailing 原生输入清单中**全部当前第四名**的 40 个局面：32 训练、8 验证，原始牌山、局面、输入和分组划分不变。这些清单早于本次开发路径复盘；不按标签收益或候选对错重新挑选，不把开发失败案例加入训练。它们不算新增独立牌山。

每个局面对全部原生合法动作使用相同的 16 个未见当前手牌山采样，固定当前暗手，克隆后续手局 RNG；之后本人按正式原 v8 策略继续，对手策略与原终局标注一致，直到原生引擎宣布比赛结束，不能在本手结束时截断。逐手计分、终局分数及同分名次核对一致。保存完整动作结局，后续可从中计算前二和脱四目标；不把未来信息写入模型输入。

先在 GPU 作业的配套 CPU 内精确重放全部 40 个前缀，验证原始输入、学生输入、教师输入、合法动作及当前第四名一致。冻结输入、代码、库、上游实现、v8 权重及工作分配。按公开合法动作数均衡分成两个互不重叠的 GPU 工作作业；上限 800 个动作、12,800 次终局分支，每个工作作业最多 90 分钟。超出公开预算或校验失败即停止，不删除不利动作。完成后逐动作核验 16 个完整结局、原标签公式和冻结指纹。

原有出牌/吃碰杠回放、和牌及守位终局标签均保留。拟合阶段尚未登记；标签完成后先检查有效信号及训练/验证分离，再明确配比和预算。拟合将从正式 **Jev Play v2/v8** 的现有 LoRA 和决策头出发，不从零训练、不叠加新网络、不沿用未通过验证的研究权重。普通局面的旧输入及冻结 v8 参考分布可以复用；新增终局目标不能伪装成原来的模仿标签。

配置：[`configs/training/endgame-native-fourth-labels-v1.json`](../../../configs/training/endgame-native-fourth-labels-v1.json)。原始数据和逐场记录保持私有，仅发布代码、方案及聚合计数。
