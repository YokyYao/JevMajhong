# Jev Unified AttackRisk v8：保留进攻覆盖，控制放铳

v7的768场独立确认复现了和牌率收益：+3.5260个百分点，95%区间[+0.7926,+6.2594]。但放铳率增加2.2415个百分点，超过预登记1个百分点限制；净点+1495.57/场的区间[-166.23,+3157.38]仍跨零。v7保留为实验模型，不替换正式模型或EXE。

## 结果诊断与假设

对全部已审计事件作描述性重数：参照/候选分别有2165/2086手，230/269手发生本人放铳，其中副露状态放铳60/96手，面对对手立直时放铳223/252手。候选有272次放铳支付事件，269手放铳，差异来自同一手多家和牌；训练惩罚与主要风险指标按是否发生放铳计一次。面对不同策略的机会和手数会改变，这些计数不能证明是哪一次吃碰或哪项奖励造成了风险，也不能直接当条件风险率比较。评测局面不会加入训练。

本轮假设：保留v7进攻覆盖，适度增强训练的放铳代价，有机会保留和牌率收益并满足原风险限制。早期惩罚2.0的模型与当前数据、初始化不同，不能由历史结果推断当前惩罚1.5一定更好。本轮只登记一个系数，不搜索多个奖励后选最好结果。

## 数据与训练配方

使用现有33408条不同训练位置（29625条专家、3783条模拟）及原620条验证，训练/验证组划分不变，不复制记录。本次不是新增数据采集。先从已审计训练未来的原始事件重算全部3783个模拟目标，复现当前标签，再改奖励：自己和牌 + 0.25 × 折扣和牌收益 − 1.5 × 是否放铳。v7的放铳系数为1.0，其余奖励不变，净点权重仍为0，速度折扣0.98。

所有动作共享同一组未来，保持256次配对重采样、温度0.05及原随机种子。旧副露标签继续按现有实际候选范围条件化。专家数据保持原字节、公开模型输入与候选不变，620条验证字节不变；不读取留出未来来生成训练目标，不使用本次确认对局作训练数据。独立事件解析和另写的重采样公式须逐条复现当前与修订目标，并核对全部数据差异。重采样不会产生新的独立证据，固定隐藏手牌与参考续打策略的偏差仍存在。

数据通过后，从v7末步2088继续同一个rank16 LoRA和动作头，新建优化器；Qwen3.5-0.8B基座不变，不叠加新网络。拟完整一轮2088步，微批1/累积16，LoRA/head学习率2e-6/1e-5，专家/模拟损失75%/25%，模拟内门清/吃碰/杠/副露40%/30%/20%/10%。每256步跑验证，末步为唯一对局候选；验证目标保持原口径，CE仅用于诊断，不与换奖励后的训练损失直接等同，不根据最低CE换候选。

## 阶段目标与停止条件

1. 数据阶段：全部3783个训练模拟目标复现及修订通过，33408条位置完整，专家字节、公开输入和620条验证不变。失败则先修复明确原因，不开始优化器。
2. 训练阶段：完成登记的2088步并核对实际33408条消费、最终LoRA/head和数据哈希；620条原生推理覆盖门清、副露、吃碰及三种杠。
3. 初筛：新8组牌山，共192场，两策略各96场，和牌率均值提升且放铳率增加不超过1个百分点才进入确认；否则停止本轮并分析改进。
4. 确认：另32组新牌山，共768场，两策略各384场；和牌率提升95%区间下界大于0，放铳率增加不超过原1个百分点。同步报告净点、一位率、前二率、四位率和实际吃碰杠，不能将单项改善解释为全部改善。未通过不补救加赛、不改选检查点、不放宽门槛。

数据准备、训练和评测分别记录，数据准备启动不表示优化器已经更新。最多两项本人运行作业，包含CPU。只公开方案、代码和聚合摘要，原始未来、逐场明细与实验权重私有；PR保持草稿，正式模型与EXE等待独立效果验证。
