# Jev Unified WinRisk v2：扩展门清收益覆盖

v1的768场独立确认未证明稳定提升：自己和牌率+0.856个百分点，95%区间跨零；速度收益基本持平、净点-634.64/场，放铳+0.975个百分点。正式模型保持现状。不能把开发192场的+4.24个百分点当作已确认改善。

训练覆盖审计发现，v1实际8192条曝光只有42个新增门清模拟位置，模拟损失来源主要来自吃碰。它提供了需要补足覆盖的线索，不是已证明的失败原因。本次同时增加覆盖和调整阶段配比，属于训练改进实验，不声称能单独归因某个改动。

## 数据阶段

已有128组完整控制牌山（512场），旧门清数据只恢复了前8组。本轮复用其中另外24组，偏移12组，以保留三种对手与四组训练/保留轮换：18组训练、6组保留，复用96场，不新模拟完整控制比赛。原日志、原划分和原审核文件不改，也不使用v1确认牌局作为训练数据。

计划选432个训练位置、144个保留位置，每组牌山最多24个；选择只根据公开局面、合法菜单和固定顺序，禁止按收益正负、argmax、是否鸣牌筛选。每位置16个共同未来，先双分支、再扩展全部可比较合法动作；原生输入、双分支和全部动作扩展各需完整独立审核。立直前后重复物理位置仍按较早合法窗口归一，不平均不同菜单，实际去重数量单独报告。

数据流水线只有恢复、标注和审核，没有优化器更新。源实现冻结为61a3411c21ac0c70a9641712969f727774bc3742fb8cc26950e58cb219678e04；213项本地核心检查通过，包含源窗口范围、对手轮换与保留划分不变检查。原有公开状态编码和收益系数保持不变。

## 拟定训练配比与预算

仍用一套Qwen3.5-0.8B LoRA及动作头处理全部操作。拟从v1明确声明的第512步完整权重继续，作为实验初始化；该权重没有通过确认，也没有晋级正式模型。用自己的冻结验证器核对父模型和恢复清单，并隔离所有祖先训练组。使用新优化器，不恢复旧优化器。

训练集拟保留32768个唯一位置。专家/模拟损失总质量仍为75%/25%，拟将模拟部分按门清40%、吃碰30%、杠20%、副露出牌10%分配，相当于总损失10%/7.5%/5%/2.5%。单例系数上限8，不复制样本，不丢弃均匀目标。实际唯一数量须完成数据审核、物理去重及池合并后冻结；任何阶段数量不足或系数超过上限即停止准备，不能静默改配比。阶段加权实现已完成：训练阶段将公开菜单/手牌推导出的阶段写入损失元数据，真实上游保留该标签用于加权，但模型请求与编码不变；未标注动作的梯度仍为零。实际配方须等全量审核后冻结，当前没有新LoRA训练。

原400例验证记录保留，拟增加144个新保留门清位置；实际总数按去重结果报告。新旧验证组成不同，不直接比较总CE。验证损失仅作诊断；效果仍由新牌山完整对局决定。

拟固定1024步，最多曝光16384条记录；rank16、BF16、微批1、累积16，LoRA/head学习率2e-6/1e-5，每256步验证。第1024步是唯一预先登记的对局候选，不按CE挑选旧步数。确切数据与实现冻结后，才允许提交优化。

收益仍为自己和牌 +0.25×折扣速度 −2×放铳，净点系数0，折扣0.98。通过数据覆盖及损失配比学习快和与防守，本轮不再同时修改收益系数。
