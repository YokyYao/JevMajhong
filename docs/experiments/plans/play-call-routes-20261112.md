# Play v1 实战鸣牌路线修复

目标是改善当前 Play 的门清鸣牌与对手立直后的路线选择，以独立完整四人东净得点和放铳作为效果依据。先解决[实战复查](../results/2026-11-12-play-input-audit/README.md)发现的问题，不继续根据残差候选的偶然开发正值切换模型。

## 已完成的定位

27份实战吃碰预测均跳过，候选已进入模型。3份补入部分核准场况仍跳过；均衡选取的12份训练输入在3种视图下均保持动作。原生缓存概率校验通过。不能将现象归为模型完全不会吃碰，也不能将输入补全视为已经解决策略问题。

门清断幺材料且吃后降低向听的训练选项仅65个，现模型全部跳过；其采样效用既有吃更好也有跳过更好。下一步针对该细分类补充真实合法状态与反事实后续，不用强制吃牌规则替代训练。

## 阶段与停止规则

1. **输入与合法性。** 保留已确认立直，公开状态改变重新推荐，记录实际模型输入，自家立直锁手。针对这部分做回归检查。对手立直自动识别仍为独立未完成项目，不能宣称已部署可靠视觉触发。
2. **12整牌山小规模数据试采。** 使用固定 Play v1、4座位、6种干预类别：门清断幺材料且降低向听的吃；门清面对立直的吃；门清役牌碰；门清面对立直的碰；普通吃；普通碰。类别只由动作前公开信息决定，不要求该操作最终更好。保留完整合法菜单和原模型跳过／吃碰两侧结果；候选中的自己手牌仍为正确两张。
3. **检查覆盖再扩容。** 按整牌山3:1划分训练／验证，同局面所有候选和相邻观察同组。先报告各路线的不同状态、操作正负采样收益和来源；稀缺路线不足时追加新牌山，不复制旧样本补配比，也不对不足的验证子组报稳定结论。第一批只是试采，不是训练完成。
4. **生成可靠排序目标。** 对选中的不同公开状态重放真实前缀，使用16个配对未来对比合法操作，覆盖混合菜单及跳过反例；核对本局净得点、速度与放铳分量。主目标沿用净得点为主、快和支持和放铳约束，先不同时改奖励和数据方案。未来结果只用于训练目标，不进入模型特征。
5. **短程拟合。** 从 Call v1 开始，只修复鸣牌路径，普通弃牌保持已部署模型。先逐轮检查训练是否学到上述路线、验证是否同时保留应跳过反例和原有吃碰能力；至多连续4轮无改善即停。先比较小规模动作头修复能否在验证上产生有效改选；若只能拟合训练或仍不能改变该路线，再评估 LoRA／表示改进，不机械增加步数。不将该步骤的偏好变化称为净得点提升。
6. **小开发、一次独立确认。** 固定候选后先用8整牌山192场开发。没有实际改选或开发收益不支持继续时停止候选并分析。通过后才注册全新32整牌山768场确认，以整牌山配对净得点95%区间下界为正作为该模拟协议的提升证据，同时报告顺位、和牌、放铳与路线子组。已消费的 Call Uniform 测试牌山禁止重新作为独立测试。

输入试采配置见[play-call-routes-native.json](../../../configs/training/play-call-routes-native.json)。首批逻辑种子11310000—11310011，已与183份已有协议核对未重叠。追加采样须另行登记，不改写本批已冻结配置。

可复用代码和聚合结果公开；完整请求、截图衍生逐条诊断、模拟轨迹和未采用权重保留私有。安装包等待模型通过评估后再更新。

首批12牌山采样已在集群启动，尚未更新参数。首个完成牌山产生17条干预记录，六类均有机会；须等待全部牌山与覆盖核对后才进入多未来标签和拟合。源码通过81项核心、55项桌面检查，共136项。

首批现已全部完成：229条干预记录，排除5条属于含杠菜单的普通策略路径，224条纯吃碰记录去重为206个公开状态（156训练／50验证）。六类在两边均有覆盖；336份四家支付／顺位记录重算通过，其中59份复用原控制结果，并非336场全新比赛。已启动每状态16配对未来标签生成；后续完整候选比较共251对（183训练／68验证），数量已在结果产生前登记。见[采样摘要](../results/2026-11-12-play-input-audit/route-data-summary.json)。当前仍为数据准备，优化器更新为0。


## 已登记的短程拟合：Jev Call Routes v1

候选直接更新 Call v1 的指针动作头（524800参数），底座、LoRA及 Discard v1 动作头冻结。它与上一轮2560参数的公开特征残差是不同方案；仍依赖原Call编码器，尚未生成或公开新权重。

新数据按完整候选集合训练：156训练状态／183对，50验证状态／68对。另从旧来源484个不同训练状态中，按固定种子选取256个状态，以原模型概率作KL约束，不使用旧未来收益标签，也不使用旧验证或独立测试状态作为锚点。锚点权重0.2，平均KL上限0.05。

目标分布为 `softmax(log 原策略概率 + 本局采样效用 / 0.05)`；奖励仍为净得点／8000＋0.1快和支持−0.4放铳。AdamW学习率1e-5、batch16、最多24轮。每轮报告完整候选的实际改选、采样净点、快和、放铳和旧策略偏移；**连续4轮没有符合约束的实际选牌净点改善即停，loss下降不延长该时钟**。保留第0轮原策略；不能用拟合loss更低替代改选收益。

训练后重算全部检查点、验证指标、冻结权重、锚点和选择过程。进入192场开发前，必须同时满足实际验证净点为正、采样效用为正、旧策略偏移在限内，并至少在一个验证“门清断幺材料且吃后降低向听”的采样正收益状态上恢复吃牌。最低子组检查只是功能证据，不是胜率证明；正反例及子组样本数会同时报告。没有这些证据时自动跳过完整比赛。

开发预留此前未消费的8逻辑牌山11410000—11410007（186份既有协议未发现重叠），三类对手、四座位、两策略，共192场，不复用旧开发结果。独立确认尚未开放。本轮检验完整修复方案，不能据此分别归因于新增数据、动作头或损失的单项贡献。
