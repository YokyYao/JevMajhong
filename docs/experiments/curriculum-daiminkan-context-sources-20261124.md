# 大明杠上下文扩展：554 个真实合法窗口，等待教师标注

原杠牌试点中，Mortal对62个非强制和牌的大明杠窗口全部选择跳过。
旧来源仅覆盖门清、上家第一次弃牌。本批先补来源覆盖，尚未证明模型能力提高。

预先固定576个计划：32个来源模板族 × 3种副露状态 × 3种出牌家 × 2个物理世界。
实际生成554个大明杠窗口，22个前缀隔离记录完整保留，没有按教师选择补样。
每个窗口都在原生环境中重放了完整前缀、自己的公开输入与合法菜单，并确认真实副露状态和弃牌家。
所有物理牌山都包含136张不同物理牌。

TRAIN保留24个来源族，验证保留8个来源族，沿用原杠牌试点的族与分区。
同一族的副露状态、弃牌家与物理世界全部放在同一区，554个窗口不等于554个独立样本。
生成前的初始／机会牌型规范化检查未发现跨接原分区的冲突，也未发现不同来源族的形状别名。
这项检查覆盖两个杠来源试点；全训练语料与最终保留族的重叠排除、编码与配比仍待后续审核。

六项来源族、物理牌山及教师公开历史遮罩检查通过，耗时0.405秒。
独立Mortal教师任务322084已提交，15分钟时限，等待现有两项GPU作业释放名额；
退出记录任务322085依赖该教师任务结束。教师尚未为本批生成标签。
它只接收完整公开前缀和自己的手牌，不接收母题、真实牌山或对手暗牌。
按实际选择汇报杠／碰／吃／跳过分布，不设置大明杠正例配额。
规则强制和牌会另记，排除在教师网络动作标签之外。

本批仍只覆盖早巡、无立直威胁、等分场景。更广的窗口不自动等于“应该杠”，
教师选择也不是最优收益证明。必要时仍需在公共信息约束世界中比较动作收益。
当前3A父损失对照继续使用原87595/23688条数据，这批来源及未来标签都未加入其训练。
