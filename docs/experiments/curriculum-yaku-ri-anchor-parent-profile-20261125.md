# Augmented 3B parent and validation adapters

The augmented 3B course can continue only from the actual final 2596-update
RI-anchor parent after its original retention and strategy criteria pass. A
new explicit parent adapter requires the completed registered budget, complete
saved-model reload, original validation cohort, all optimizer states, source
and exposure identity, independently audited execution and actual terminal
records. It refuses an interim peak, failed strategy, changed source, missing
parent or automatic production promotion. It inherits adapter and head weights
with a fresh optimizer. The original parent registration and policy remain
unchanged.

The proposed child recipe has 2698 updates over two complete physical epoch
plans, with 196954 exposures from 96222 distinct training records. Curves are
scheduled at steps 0, 1349 and 2698. Validation has 25826 menus: the original
23688, 1310 additional basic decisions, and 828 route decisions. Original
retention is judged on the original cohort; the additional basic cohort is
reported separately. Canonical validation does not include a TRAIN-only
parent-anchor penalty. The retained-source validation losses and six route
losses reuse their existing numerical functions.

Ten focused tests passed in allocated GPU resources. A full actual validation
formatting check also passed: it reused 23688 real cached predictions from the
current 1236-update checkpoint and supplied uniform fixture predictions only
for the 2138 additional menus. All 25 shared original profile fields matched
the saved real profile exactly. Complete 24998-parent menu identity and
probability-shape checks passed against the 25826 child corpus; the original,
supplement and route cohorts were disjoint and complete. Sources were hashed
before execution and every actual imported project helper was covered and
unchanged afterward.

These are adapter and data-format results. Uniform fixture predictions are
not evaluations of future 2596/2698 weights. The actual missing parent was
refused, no model or optimizer was loaded, no student update or new game ran,
and no parent seal or child registration was created. The full augmented 3B
registration, actual token/optimizer integration and finite fit/audit lifecycle
still need preparation before that course can start. The current 2472-update
fit and its frozen inputs are untouched. Raw predictions, dataset identities
and scheduler records remain private.
