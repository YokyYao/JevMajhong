# 原有决策头容量：19 个训练例子可以拟合

该诊断仅检验训练集拟合能力，不产生发布候选，也不证明麻将胜率或泛化能力改善。

实际使用正式 v8 对 19 个既定训练输入进行编码。全部编码未截断，包含公开分数、末盘上下文及分差，不含终局目标元数据。19 次预测与已有 v8 缓存的概率最大差为 **0**，首选改变 0 次；用实际捕获的表示重放原有 PointerHead，概率差同样为 **0**。

随后冻结表示，只在内存副本中更新原有 524,800 参数决策头，不更新编码器或 LoRA，不叠加网络。19 个例子等权完整 batch，AdamW 学习率 1e-3，仅用于能力探测。
