# 3B 第 625 步开发集结果

3B 从此前选出的 3A 第 1800 步权重继续训练。第 625 步已完成全部 24,516 条验证记录和 16 场完整东风对局。下面比较的是同一模型分支的第 0 步与第 625 步：验证数据、模拟种子、对手类型、座位和执行策略相同，变化来自训练后的参数。

| 指标 | 3B 起点 | 3B 第 625 步 | 变化 |
| --- | ---: | ---: | ---: |
| 前二率 | 87.50% | 81.25% | −6.25 个百分点 |
| 平均净得点／场 | +4,306.25 | +10,412.50 | +6,106.25 |
| 和牌率 | 22.45% | 25.63% | +3.18 个百分点 |
| 放铳率 | 6.42% | 3.67% | −2.75 个百分点 |
| 一位率 | 56.25% | 50.00% | −6.25 个百分点 |
| 四位率 | 12.50% | 12.50% | 持平 |
| 对局 reward：净得点／8000 | 0.53828 | 1.30156 | +0.76328 |
| 验证总目标损失 | 1.04924 | 1.04242 | −0.00682 |
| 验证加权目标 CE | 1.03889 | 1.03486 | −0.00403 |
| 验证自然分布 CE | 0.93195 | 0.93345 | +0.00150 |
| 新增路线的加权目标损失项 | 0.18541 | 0.17971 | −0.00569 |

和牌率与放铳率均先逐场计算，再对完整对局取平均。新增路线的加权损失项是固定配比下的验证指标，不是实际对局 reward，也不能证明已掌握某种罕见役。加权 CE 小幅改善，自然分布 CE 小幅上升，两者均保留报告。

这组对局的净得点、和牌率和放铳率方向较好，但前二场数从 14／16 降为 13／16，一位场数也少了一场。因此不能概括成所有指标都提升。净得点与名次可以出现不同方向：赢分幅度更大，并不必然增加进入前二的场数。

只有两个已参与开发的模拟种子组，样本较小，而且起点经过此前的开发集选择。这些数据不能证明稳定提升，不能证明超过冻结 v8，也不替代最终独立对照。这里没有计算或声称独立胜率置信区间。

训练继续执行已登记的 2500 步方案，后续观察点为 1250、1875、2500 步。本次结果不改变训练配比，不新增模拟种子，不重新选择父模型，也不替换已发布工具的权重。
