# Curriculum stage1: cleaned data and seven-pairs audit

This report describes data admission and a read-only historical audit. It does not claim the new model has improved; stage1 has a separately registered fresh-base fit.

## How hand types enter the data

The published v8 dataset samples **decision windows**, not a prescribed mixture of winning yaku. Its29,625 expert records contain a public observation, legal candidate descriptions and the observed chosen action. Its3,783 simulated records contain action-preference targets from paired continuations. There is no predeclared percentage of chiitoitsu, tanyao, yakuhai or high-point wins. The public decision records do not include a future winning-yaku label, so a final-yaku distribution cannot be recovered from them alone.

The v8 simulated objective is own-win +0.25 discounted own-win −1.5 deal-in, with net-point weight0 and no seven-pairs bonus. Completed-hand yaku/shape, a current hand's shanten route, a UI explanation and an action's true expected value are distinct quantities.

## The UI explanation is a separate heuristic

The currently published desktop `hand_strategy` function displays the seven-pairs direction when its closed-hand flag is true and at least five tile kinds have count≥2. It does not compare regular-hand and seven-pairs shanten and is explicitly documented as an explanation heuristic, not model reasoning. Such a message alone is not evidence that the model chose a seven-pairs plan. A regression case with five pairs and a better regular-hand distance illustrates the limitation. The desktop code is not changed in this model-training work.

## Decision-shape proxies and the candidate guard

Among15,419 no-meld closed-hand menus in the published v8 TRAIN data,11,453 have lower regular-hand distance,1,507 have lower seven-pairs distance and2,459 tie. These are current-shape proxies, not percentages of eventual wins. Five pair kinds are present before acting in662 menus.

For11,938 menus with sufficient public riichi information, the existing serving guard excludes every best-regular-distance discard in458 cases. This is consistent with the guard using the minimum distance across hand structures, but it does not prove that those excluded moves are superior or that seven-pairs caused a loss; other special-hand routes can also affect the minimum. Another3,481 incomplete-riichi menus are explicitly skipped for this guard diagnostic, not assumed safe. No policy weights were loaded and no new policy games generated by this audit.

The audit did not justify adding a penalty to chiitoitsu or fabricating a fixed yaku quota. Preserve legitimate seven-pairs choices and evaluate competitive regular/seven-pairs decisions separately.

## Cleaned curriculum data

Starting with the exact published33,408/620 files, reserve20% of TRAIN source groups using seed2026112001 and a label-blind public-group hash. The675 reserved groups are removed from **all** subsequent stage training. Preserve the old validation groups. Isolate rows with unknown score/riichi/dealer/wind/hand-number metadata rather than silently completing their state:4,180 TRAIN rows and807 validation rows are excluded after regrouping. No examples are duplicated and no observed action or simulated target is relabelled.

Per-example weights are0.84224 for plain and3.98798 for either riichi stratum, below the cap8. These loss-only tags are verified to leave every visible input unchanged.

Stage1 teaches discard/riichi. **It does not include win/pass supervision or learned scoring.** Legally available wins are taken by the existing rule. Endgame decisions about passing an insufficient win remain stage4 work and require new, separately admitted data.
