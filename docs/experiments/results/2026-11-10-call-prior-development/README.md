# 吃碰先验校正：完整开发评估

768 场评估已完成，独立逐场审计通过。本轮 trust15 相对已确认旧模型的平均净得点在两组均略高，但区间很宽，尚未证实稳定提升；相对上轮 call150 也没有一致优势。保持候选冻结，优先用预留的新牌山复验，不在同批牌山上继续选检查点，不部署。

## 本轮训练

先用 32 场新 TRAIN 比赛的 1024 条自然反应估计先验（吃 78、碰 132、跳过 814）。完整先验加权虽降低验证 NLL，却使原生吃牌召回归零，60 步停止且不进入对局。

随后从 call150 重新起步，将完整先验权重与 1 各半，加入冻结 call150 的 KL 惩罚（系数 2），学习率 1e-5、batch 256，只更新独立鸣牌头 query。复用已审计的 4096 条训练反应三视图特征；新先验记录仅估计权重，并未加入特征训练。每 5 步验证、耐心 6 次，45 步停止，按自然验证 NLL 及保留类别召回规则选中继续训练后的 15 步。原弃牌头、底座、LoRA、key 均冻结。

验证 NLL 从 0.51473 到 0.47323。完整动作的吃牌精确率由 4/37=10.81% 到 3/20=15.00%，召回率由 4/23=17.39% 到 3/23=13.04%；动作类别正确不等于吃牌组合正确。16 场比赛、512 条验证是开发证据，不是新测试。旧测试没有用于本轮选模。

## 全部开发对局

32 个独立逻辑牌山，四座轮换，每策略每组 128 场；两组共用同一批 32 个牌山，不能按 64 个独立牌山统计。使用 spaced-v1 种子方案。净得点为整场终局分减 25000，不是单手番数或先和牌比例。

`scripts/audit_call_development.py` 已对全部 768 个唯一对局核对三方策略、32牌山×四座、所有均值和比率、三组配对差及按牌山聚类的 Student-t 区间；同时检查候选校验和、旧头与冻结参考文件、JevAny模型实现和活动评估代码。完整审计状态为 `passed_complete`。

## 下一阶段

独立复验保持 trust15 不变，使用预留牌山 8610000–8610127、同样四座/三模型/两组对手，共 3072 场。主要对照仍是已确认旧模型，call150 为次要对照。两组均要求相对旧模型的配对95%区间下界大于零，且候选平均净得点非负；否则不得宣称已确认提升。没有固定 +250/+500 点的否决线。复验不更新参数、不重新选候选，结束后自动运行完整审计与判定。

自然新数据已准备：8192训练、2048验证、2048封存测试，来自与旧实验隔离的新比赛。当前只准备数据，不用新测试选模型。若复验不支持当前改进，再分析错误并利用新的训练/验证数据改配方；新测试保持封存，待下一阶段明确冻结候选与协议后使用。

复验在 Slurm 分配的一张 GPU 上运行，先检查没有其他计算进程。每分钟观察进程与评估共享作业分配，最多观察7小时，批作业上限6小时；仅在完整审计和判定均产生后标记完成。观察器不能唤醒聊天，后续分析依赖已恢复的 active 持续目标。代码、配置和本摘要公开；原始牌谱、逐场记录、特征缓存及新权重保留私有。
