# 快和奖励：动作配比与直接排序短程对照

## 结论

纯快和直接排序候选的192场完整开发已完成：相对 Jev Play v1 的样本净得点 **−2312.50点／场**，8个独立牌山的配对95%区间 **[−6390.02，1765.02]**。本轮未显示可靠提升，不采用此候选，也不启动其长确认。

调整后的 Jev Tempo Safe v1 曾在开发中得到+1117.71点／场，但768场独立确认相对 Jev Play v1 为 **−736.46点／场**，区间 **[−2534.24，1061.33]**，未确认提升，不采用。扩充数据续训的开发也未改善。现用策略仍为 Jev Play v1，当前继续检验以实际本局净收支为主的 Jev Value v1。

## 数据与对照

使用同一批96个原生牌山的975条单动作反事实分支。按整个牌山划分：72个训练牌山、716条训练样本；24个内部验证牌山、259条样本。真人封存测试集未打开。每条标签比较同一公开状态下两个合法动作，之后按冻结策略续打，用实际本局和牌及速度产生收益差；一次采样结果不等同于普适最优动作。

三种训练均从 Jev Discard v1 和 Jev Call v1 的原动作头初始化，冻结底座和 LoRA，使用相同种子、学习率 `1e-5`、批量16、KL系数0.05。每个候选均训练3轮，共135次更新。新模型和逐场数据保持本地，只公开代码和汇总。

| 候选 | 区别 | 各自目标下的内部验证损失 |
| --- | --- | --- |
| Jev Tempo v1 | 原自然比例、相对参考动作边际 | 0.114870 → 0.103073 |
| Jev Tempo Balanced v1 | 操作／收益方向分层，单样本权重最多4 | 0.114870 → 0.101976 |
| Jev Tempo Rank v1 | 保留相同分层，改为直接排序，仍有KL约束 | 0.154261 → 0.110384 |

前两种损失口径相同；第三种改变了目标，不能拿绝对损失值横向排名。权重上限使实际训练损失占比约为普通决策41.10%、吃13.64%、碰13.64%、暗杠11.00%、大明杠10.36%、加杠10.26%，没有复制样本来填配额。

## 动作诊断

每种操作按收益方向最多检查8条验证案例，确定性选取。下表仅列有利操作方向：

| 操作 | 验证案例 | Balanced：实际选择该操作 | Rank：实际选择该操作 | Balanced → Rank 平均操作概率 |
| --- | --- | --- | --- | --- |
| 吃 | 5 | 0 | 0 | 6.15% → 31.49% |
| 碰 | 7 | 3 | 4 | 32.30% → 55.28% |
| 暗杠 | 2 | 0 | 0 | 14.23% → 14.70% |
| 大明杠 | 5 | 0 | 0 | 19.88% → 35.25% |
| 加杠 | 0 | 无法评估 | 无法评估 | 无法评估 |

这些是模型操作偏好，不是和牌概率。不利操作方向中，Rank仍有1/8不利吃牌和1/6不利碰牌被实际选中。不能用“鸣牌更多”宣布学会了。

训练集有利暗杠只有3条、有利加杠只有2条；验证集缺少有利加杠，其他稀少操作也不足预期覆盖量。Balanced在这3条有利暗杠训练样本上的平均暗杠概率从原策略7.06%降至5.22%。这提示问题可能包含训练目标和梯度竞争，不只是动作概率尚未越过决策阈值；数据稀缺与标签噪声仍需另行排查。

直接排序弱化已正确排序样本的梯度，优先修正顺序错误；这是本轮待检验的优化假设，不构成其最终实力优于原方法的证明。

## 延长训练与后续

同配方延长至最多12轮，连续2轮验证不改善即停：第1至5轮验证损失依次为0.123382、0.114040、0.110384、0.111542、0.111115。实际225次更新后停止，选中第3轮。已逐张量核对：延长运行的入选动作头与短训的第3轮完全相同，不是另一个性能更好的模型。

## 风险奖励调整与新增数据

新奖励为 `本局折扣和牌奖励 − 0.3×是否放铳 + 0.1×tanh(本局净得点/8000)`。保留速度与和牌主项，不按吃碰杠次数发固定奖励；只计算介入所在牌局，后续局不计入该动作标签。一炮多响只扣一次放铳项，本局净得点仍计算实际全部支付。

先复用同一批实际分支日志重算训练标签，保留原始快和标签与公开输入。从同一冻结模型初始化、保留分层权重、直接排序和KL：Jev Tempo Safe v1 在第8轮、360次更新后早停，选中第6轮；其内部验证损失按新目标从0.256693降至0.173104。新目标与纯快和不同，此数值及其专项正负例不能直接横向排名。

新候选的开发对照覆盖192场，其中96场参考臂复用已审计记录，只新增候选的96场。复用前核对阶段、牌山、规则、参考模型及出牌源码；完成后已从全部原始事件重算得分和速度，并核对参考臂逐场记录完全一致。

## 扩充数据续训结果

新增96个牌山最终得到1353条分支。合并原975条后共2328条：1741条训练、587条验证，对应144个训练牌山、48个验证牌山。数据来源、全部分片、原生结算、冻结编码器和起点权重核对通过。Safe Data v1实际训练5轮、545次更新后早停，按当时的混合验证均值选中第3轮；第0轮与Safe v1起点逐张量相同，入选轮次确实产生参数变化。

只新增候选96场、复用参考96场的完整开发中，相对Play的净得点差为 **−508.33点／场**，区间[−4596.04，3579.37]；复用父模型已有记录做同牌山比较，相对Safe v1为 **−1626.04点／场**，区间[−3631.64，379.55]。未显示增益，不进入该候选的独立确认。

专项诊断按新旧来源各抽取每种操作正负方向最多4例。部分正向效用标签仅代表该次续打少支付一些点数，不代表“必须鸣牌”的绝对最优解；旧风险标签下新增验证缺少加杠正向案例，不能记成通过。最终强度仍以完整独立牌山得点验证为准。

## 下一轮：实际本局得点为主

前两种速度主导配方都未确认净得点提升；旧点数项以0.1倍tanh计入，压缩了大额收支的幅度。新Value v1采用 `本局净得点/8000 + 0.1×本局折扣和牌奖励 − 0.1×是否放铳`，不直接奖励番数或鸣牌次数。使用实际支付，失败牌局的损失也进入标签；仍只计算介入所在牌局。

采样续打策略为Jev Play v1。新候选从同一现用策略的动作头出发，复用上述实际分支重新计算标签，不追加模拟采样。底座与LoRA冻结，仅训练两个动作头；按最新来源328条验证样本选模，同时报告原来源表现。第5轮、545次更新后早停，保留第3轮；新来源损失0.496202→0.274933，原来源0.458587→0.270278。新目标的损失不能与旧奖励数值横向比较，训练改善尚不是比赛提升证明。
