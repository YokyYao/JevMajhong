# 快和奖励：动作配比与直接排序短程对照

## 结论

纯快和直接排序候选的192场完整开发已完成：相对 Jev Play v1 的样本净得点 **−2312.50点／场**，8个独立牌山的配对95%区间 **[−6390.02，1765.02]**。本轮未显示可靠提升，不采用此候选，也不启动其长确认。

调整后的 Jev Tempo Safe v1 曾在开发中得到+1117.71点／场，但768场独立确认相对 Jev Play v1 为 **−736.46点／场**，区间 **[−2534.24，1061.33]**，未确认提升，不采用。扩充数据续训的开发也未改善。Jev Value v1的768场独立确认也未显示净得点改善。现用策略仍为 Jev Play v1，下一轮针对副露后面对立直的稀缺训练局面补充数据。

## 数据与对照

使用同一批96个原生牌山的975条单动作反事实分支。按整个牌山划分：72个训练牌山、716条训练样本；24个内部验证牌山、259条样本。真人封存测试集未打开。每条标签比较同一公开状态下两个合法动作，之后按冻结策略续打，用实际本局和牌及速度产生收益差；一次采样结果不等同于普适最优动作。

三种训练均从 Jev Discard v1 和 Jev Call v1 的原动作头初始化，冻结底座和 LoRA，使用相同种子、学习率 `1e-5`、批量16、KL系数0.05。每个候选均训练3轮，共135次更新。新模型和逐场数据保持本地，只公开代码和汇总。

## 动作诊断

每种操作按收益方向最多检查8条验证案例，确定性选取。下表仅列有利操作方向：

| 操作 | 验证案例 | Balanced：实际选择该操作 | Rank：实际选择该操作 | Balanced → Rank 平均操作概率 |
| --- | --- | --- | --- | --- |
| 吃 | 5 | 0 | 0 | 6.15% → 31.49% |
| 碰 | 7 | 3 | 4 | 32.30% → 55.28% |
| 暗杠 | 2 | 0 | 0 | 14.23% → 14.70% |
| 大明杠 | 5 | 0 | 0 | 19.88% → 35.25% |
| 加杠 | 0 | 无法评估 | 无法评估 | 无法评估 |

这些是模型操作偏好，不是和牌概率。不利操作方向中，Rank仍有1/8不利吃牌和1/6不利碰牌被实际选中。不能用“鸣牌更多”宣布学会了。

训练集有利暗杠只有3条、有利加杠只有2条；验证集缺少有利加杠，其他稀少操作也不足预期覆盖量。Balanced在这3条有利暗杠训练样本上的平均暗杠概率从原策略7.06%降至5.22%。这提示问题可能包含训练目标和梯度竞争，不只是动作概率尚未越过决策阈值；数据稀缺与标签噪声仍需另行排查。

直接排序弱化已正确排序样本的梯度，优先修正顺序错误；这是本轮待检验的优化假设，不构成其最终实力优于原方法的证明。

## 延长训练与后续

同配方延长至最多12轮，连续2轮验证不改善即停：第1至5轮验证损失依次为0.123382、0.114040、0.110384、0.111542、0.111115。实际225次更新后停止，选中第3轮。已逐张量核对：延长运行的入选动作头与短训的第3轮完全相同，不是另一个性能更好的模型。

## 下一轮：Jev Value Defense v1

先以冻结Value v1的两个入选动作头采集其真实到达的新局面。强对手仍使用原Discard v1，临时切换玩家动作头后必须恢复，不能连同对手一起改掉。新增48个独立训练牌山，每个四座位；整牌山划分为36个训练、12个内部验证牌山，独立于本轮确认集。

每个座位保留普通、吃、碰、暗杠、大明杠、加杠六类干预，再增加副露后面对立直的普通决策、对手立直时的吃、对手立直时的碰三类。只按介入时可见状态选择局面；随后比较一个实际合法替代动作与行为策略的动作，不按未来结果挑选采样局面，不强迫鸣牌。缺少操作窗口就记录缺失，不复制其他局面冒充。采样阶段不更新任何参数。

继续使用Value v1的净得点主目标和相同系数，冻结底座与LoRA；此次主要改变候选策略产生的状态数据与训练配比，不同时搜索一组新奖励系数。合并原两批完整数据作为回放，各批缓存概率必须分别与其真实采样策略核对，不能把新策略概率误当成旧模型概率。两套动作头从Value v1继续，重建优化器；每轮训练同时包含新旧来源。

训练操作占比保持普通40%、吃碰与三种杠各12%；在操作／收益方向内再按公开风险上下文分层，目标为副露且面对立直40%、其他面对立直20%、无对手立直40%。单条权重上限仍为4，报告实际有效占比；缺失分层不会被复制填满，目标比例不保证全部实现。KL仍对应各数据来源的行为概率，不把后验收益作为输入。

2. 正式拟合前，新增来源的副露立直子集至少具有32条训练、8条内部验证的非零收益对比。不足就补充新牌山，不把重复样本当作新增数据。这只是覆盖下限，不是统计强度证明。
3. 最多8轮、连续2轮未取得合格验证改善即停；按最新来源验证均值选模，且副露立直子集损失不得高于起点；原来源继续报告。第0轮参与选模，不能因整体损失下降而掩盖该子集退化。
4. 只有得到不同于起点、满足验证检查的候选才进入8个全新牌山的192场短开发；仍以相对Play v1的净得点为主，检查和牌、放铳、一位与四位及吃碰杠表现。无改善就改方案，不重复追加同配方长训。
5. 开发正向的固定候选才使用另32个未看过的牌山、768场独立确认。当前已分析的确认牌山不再是新候选的独立测试。只有完整配对净得点区间下界为正才宣称该模拟协议内改善。
