# 终局和牌标签：255 个有效局面，尚不是学生模型成绩

这批数据面向第四阶段的终局位次策略：落后时判断当前小和是否足以追分，领先时保留及时和牌的能力。
固定选取的 263 个分数视图已全部处理，得到 **255 个有效软标签、8 个采样隔离记录**。
合并过程核对了源局面、动作、分区、两组模拟结果及原生结算，并从保存结果重新计算标签。

同一个物理局面可以派生多个分数视图，记录数不等于独立牌局数。
这些是监督训练及开发验证数据，不能当作最终未见测试集，也不能把 255 个视图当作 255 个独立统计样本。
8 个隔离记录仍被保留；采样不足的局面没有使用残缺结果或按收益挑选替代样本。

“选择继续”指这批软目标的最大值动作，平分按预先定义的和牌优先规则处理。
它表示近似教师在所采样世界中的偏好，不是专家最优答案，也不是学生模型已经会拒绝小和。
领先场景中，多数标签保留当前和牌；落后场景中，标签同时考虑追分机会，而非统一要求拒绝小和。

## 标签怎样生成

每个有效局面完成两组各 16 个公共信息约束下的模拟世界，共 32 个。
在同一世界中比较当前和牌与原生合法的继续动作，并推进到完整对局结算。
普通后续决策由冻结 v8 提供，对手使用固定效率／鸣牌启发式策略；
未来和牌机会也有预算受限的继续规划。这与让 Mortal 直接给出终局最优答案不同。

落后场景首先比较终局前二机会，再比较最终名次及有界净得点。
目标保留 512 次 bootstrap 计算得到的不确定性，未设置逐局“脱四率不能下降”的否决规则。
这些分数条件化模拟不能代表雀魂真人玩家分布；公共牌山先验、固定对手和有限后续规划都限制标签质量。
软目标也不能作为模型预测和牌概率。

两组模拟偏好一致的局面有 **209／255**；逐次留出一个模拟世界后，均保持原整组模拟点估计选择的局面有 **224／255**。
这里的点估计选择不一定与 bootstrap 软目标的最大值动作相同。
其余局面仍以带不确定性的标签保留，没有仅筛选看起来稳定、获益为正的样本。
这些数值是教师标签的敏感性诊断，不是学生胜率或模型提升置信区间。

## 在当前训练路线中的位置

当前运行的 3A 数据和配方保持冻结，这批标签尚未加入其训练。
它们已按后续终局输入约定整理，并保留全部原有 3B 回放对象。
最终第四阶段数据还需合入非和牌决策、完整和牌菜单控制及和牌／立直／杠的针对性标签，
再依据实际数量确定配比、重复曝光上限和完整训练预算。

因此，本批数据完成不等于第四阶段已经开始训练，也不证明新模型比 v8 强。
学生效果仍要通过同规则完整东风对局衡量，最终独立测试尚未开启。
本报告仅公开分类汇总；原始手牌、牌山、逐世界结果和详细标签记录保持私有。
