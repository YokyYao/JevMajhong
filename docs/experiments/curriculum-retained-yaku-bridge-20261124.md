# A finite scheduler bridge continues only the qualified parent

Actual GPU bridge322577 is queued after terminal-capture322024. The source
and its held job ID/dependency were bound before parent completion. Six
allocated-node admission/capture/dependency tests pass. Its request is one
GPU/one CPU/4GiB, five minutes; it executes once and contains no polling.
The parent3A fit, independent audit and terminal capture remain unchanged.

The bridge first preserves the capture job's real completed scheduler record
and exit receipt, then checks the original qualified final2400 grade, full
independent evidence, unchanged sources and genuine successful fit/audit
exits. It invokes the already-bound retained3B launcher only if these checks
pass. Failed or missing evidence produces an explicit failed bridge record;
no grade is overridden. Existing matching child queues are preserved without
restarting a model or overwriting artifacts.

The first child preparation additionally depends on successful bridge
completion and cancels if that dependency becomes invalid. The unchanged
launcher still binds actual held preparation/fit/audit/capture IDs before
release. Its subsequent compute chain therefore cannot run before the bridge
finishes; failures/timeouts invalidate the dependent preparation. The
temporary scheduler-process adapter changes only this first sbatch command
and is restored after submission. Model formulas, data and the remaining
dependencies are unchanged.

Queuing322577 does not qualify the running parent or submit3B student jobs.
It allows continuation after actual qualification without a continuous
observer. No source array, optional acceleration environment, fourth-course
model, final reserved game or main/Windows artifact was changed. Only source,
tests, plan and this aggregate are public. See the
[bridge plan](plans/curriculum-retained-yaku-bridge-20261124.md).
